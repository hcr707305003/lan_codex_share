# 外部 Share 进程检测与强制关闭

日期：2026-09-16。状态：用户已确认，当前分支实现与回归验证完成；未提交、打包或发布。

## 目标与范围

桌面客户端识别使用当前 LAN 配置、由命令行脚本或其他桌面客户端启动的 Share，并提供单独确认后的强制关闭入口。现有 ServiceProcess 继续只管理自身创建的进程；外部识别和关闭单独处理，不把外部 PID 伪装成自己的 Popen。

本次只扩展 Share 的外部检测和控制，不扩展外部 frpc/cloudflared 的管理。不得启动、停止或重启 PHP/Webman 或其他业务服务。开发验证使用模拟对象或专用测试进程，绝不对用户现有 Share 执行强制关闭。

## 识别与显示

- 后台周期检测，不在 Qt 250ms 界面刷新中同步扫描全部进程或等待网络。
- 核对可识别的 Share 启动入口、配置文件规范化绝对路径、PID、进程创建时间及监听端口归属。兼容源码 `python -m lan_codex_share`、脚本入口和打包的 Share 程序；排除 `cli` 模式、桌面 GUI 主进程和普通 Python 进程。
- 显式相对 `--config` 相对于目标进程工作目录解析；未指定配置时按目标程序的默认目录规则处理。无法可靠确定目录时不提供强制关闭。
- 正在运行且身份匹配时显示“运行中（外部启动）”及 PID；进程存在但尚未监听时显示“启动中（外部启动）”。禁止重复启动。
- 只有端口占用、无可靠 Share 身份时显示“端口被其他程序占用”或“无法确认进程身份”，不提供杀进程按钮。权限不足时明确显示无法验证，不能误标为已停止。
- 多个匹配实例不任意选择，显示歧义并要求用户检查；不批量终止。
- 外部实例退出后自动刷新状态。外部状态不伪造为本客户端采集的实时日志；不输出完整命令行或密钥。

## 强制关闭

1. 已确认身份的外部 Share 提供“强制关闭…”按钮。
2. 点击后显示进程标识、配置位置及警告：任务可能中断，正常清理可能无法完成。默认取消。
3. 用户确认后，在后台重新验证 PID、创建时间、启动入口和配置身份；与对话框目标不一致则拒绝执行并刷新，防止 PID 重用或服务重启后误杀。
4. 仅终止该 Share 主进程和能够独立证明由该实例启动的 App Server 进程。进程归属证据必须同时关联 Share 实例身份；只凭端口、进程名称、通用父子关系或残留状态文件不足以关闭 App Server。
5. 复用的、由其他程序启动的 App Server 不关闭。旧实例缺少足够归属证据时，只关闭已验证 Share，提示关联 App Server 未处理，需要用户检查；不得扩大范围。
6. 不递归杀业务子进程，不调用按名称全局结束进程的命令，不删除会话历史或配置文件。重复点击期间禁用按钮。
7. 等待结果有超时限制；进程消失视为已退出，权限不足或超时明确报错，不声称关闭成功。完成后重新检测；不自动重启服务。

关闭桌面窗口或 Ctrl+C 只关闭桌面自身管理的服务，不能自动关闭外部 Share。强制关闭必须来自该按钮及其确认动作。

## 归属证据与兼容

优先使用现有可验证的进程信息；必要时在新 Share 启动流程记录最小实例标识（配置路径、PID、创建时间及自建 App Server 身份），不记录 token、密码或会话内容。记录仅辅助发现，操作前仍核验实时进程，不能单凭记录授权终止。

缺少新记录的旧脚本实例仍须支持可靠识别与关闭 Share 本身；无法证明归属的 App Server 保持不动。不同配置、不同服务和其他 Codex 客户端不受影响。

## 验证

测试源码/打包入口、相对配置、默认配置、CLI 排除、配置不匹配、端口误占、权限不足、PID 重用、确认期间退出/重启、多实例歧义、取消确认、重复点击、终止失败、外部进程消失，以及关闭桌面不终止外部实例。

App Server 测试覆盖自建与复用区分、旧实例无记录、残留或不匹配记录、非 App Server 业务子进程不被终止。Qt 测试验证显示和按钮状态；全量回归后报告结果。此次不提交、不打包发布。
