# 全 Session 项目目录设计

日期：2026-08-26

## 目标

当配置显式设置 `session_ids = []` 时，共享服务从本机 Codex App Server 获取全部未归档主 Session，并在网页中按“项目 → Session”展示。用户选择某个 Session 后，可以查看其完整历史、实时进度并继续发送消息。

## 配置语义

- 显式 `session_ids = []`：启用全部 Session 目录模式。
- `session_ids = ["…"]`：保持固定共享列表模式，只允许访问指定 Session。
- 未配置 `session_ids` 且未配置旧版 `session_id`：保持现有单会话自动模式，继续复用状态文件中的 Session，必要时创建新 Session。
- 旧版 `session_id = "…"`：继续作为单个固定 Session 使用。

配置解析必须保留“未配置”和“显式空数组”的区别，不能再将二者都转换为空元组后使用同一逻辑。

## Session 发现

全部 Session 目录模式通过当前 Codex App Server 的 `thread/list` 接口分页读取，直到 `nextCursor` 为空。

目录只保留：

- 未归档 Session；
- 非临时 Session；
- 没有 `parentThreadId` 的主任务，排除子代理任务。

目录按最近活跃时间降序排列。项目优先使用 `projectId` 作为稳定分组键；没有 `projectId` 时，使用规范化后的 `cwd`。项目显示名取 `cwd` 的末级目录名，并保留完整路径用于区分同名项目和辅助提示。

## 加载与运行

发现阶段只加载 Session 元数据，不为所有 Session 同时建立完整会话连接。

用户首次选择 Session 时，服务按需创建对应的 `LanChatService`，使用该 Session 自己的 `cwd` 恢复真实任务，并将服务缓存在 Hub 中。后续浏览器访问相同 Session 时复用该服务，因此队列、流式回复和执行状态对所有浏览器一致。

目录在后台定时刷新。新建或重命名的 Session 无需重启共享服务即可出现；已经按需连接的 Session 在目录刷新后继续保持连接。Session 被归档或删除后，从可选目录中移除；若它仍有正在执行的任务，则在任务结束后再释放缓存服务。

固定列表模式和单会话自动模式继续使用现有的启动时连接流程，不引入目录刷新开销。

## 网页交互

左侧栏改为可折叠的项目分组，每个项目下显示 Session 名称、短 ID 和状态。当前 Session 保持高亮，URL 继续携带 Session ID，刷新页面后恢复当前选择。

Session 未按需连接时，状态来自目录元数据；连接后，状态、队列数量和处理进度来自实时服务。多个浏览器可以同时查看不同 Session，Hub 的事件广播会使所有页面收到目录和任务变化。

顶部保留当前 Session 信息，但不再承担全部 Session 的平铺导航。

## 工作区与文件预览

按需恢复 Session 时使用其真实 `cwd`，避免把其他项目的任务错误地切换到配置中的默认 `workspace`。

在全部 Session 目录模式中，已发现 Session 的 `cwd` 自动加入文件预览授权根目录；固定列表和单会话模式仍使用 `workspace` 与 `preview_roots`。这与“共享本机全部 Codex Session”的权限范围一致，README 必须明确提示该模式会暴露这些项目给局域网访问者。

## 错误处理

- 目录获取失败：保留最后一次成功目录并显示连接错误，不清空现有页面。
- 单个 Session 恢复失败：只在该 Session 显示错误，不阻止其他项目和 Session 使用。
- 空目录：网页显示“没有可共享的 Codex Session”，服务不会自动创建替代 Session。
- 重复 Session：按 Session ID 去重，以最新目录元数据为准。
- 分页异常或响应格式无效：记录不包含用户消息内容的错误日志，并继续使用最后一次成功结果。

## 测试

- 配置测试覆盖未配置、显式空数组、固定数组和旧版单 ID 四种语义。
- App Server 客户端测试覆盖 `thread/list` 分页、过滤、去重和无效响应。
- Hub 测试覆盖项目分组、按需连接、并发复用、目录刷新与单 Session 故障隔离。
- 网页测试覆盖项目分组结构、选择与 URL 恢复。
- 回归测试保证固定 Session、队列、流式回复、图片和文件预览仍正常。

## 验收标准

1. `session_ids = []` 启动后能看到本机全部未归档主 Session，并按项目分组。
2. 新 Session 能在不重启服务的情况下出现在目录中。
3. 选择任意 Session 后使用其真实项目目录继续对话。
4. 多个浏览器查看同一或不同 Session 时均能收到实时状态。
5. 一个 Session 加载失败不会影响其他 Session。
6. 固定数组、旧版单 ID 和未配置时的原行为保持兼容。
