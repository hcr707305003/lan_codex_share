# Cloudflare YAML 表单编辑

用户确认范围：Tunnel ID/名称、凭证 JSON 文件选择、公网域名、本地回源地址；保留高级 YAML 编辑，保存才写入，不自动重启。

## 交互与边界

- 常规 YAML 默认进入表单。四个字段有固定标签；文件路径可输入或通过原生选择器选择，不读取凭证内容。
- 多条已有 HTTP(S) 域名入口可选择编辑，不新增通用代理管理；catch-all、path、originRequest 等其他字段原样保留。
- 创建示例的回源端口取当前 Share 配置；已有回源不在加载时覆盖。提供“使用 Share 地址”按钮，只更新草稿。
- 高级模式完整保留；锚点、别名、无可编辑域名 HTTP(S) 入口等复杂 YAML 保持高级模式并解释原因，不重建文件。
- 仅替换更改字段的 YAML 标量；缺失顶层凭证字段按普通块映射新增。保留未知字段、注释、规则顺序。无法安全修改时保留输入并提示高级模式。
- 切换入口先应用上一入口草稿到内存，失败则停留原入口；切换模式不写文件。保存使用原 ConfigDocument 并发检测、校验及公网入口同步。
- Token 模式显示说明：本地 YAML 表单不会更新 Cloudflare 远程配置，不改变启动模式。
- 用户要求留在当前分支；不提交、打包、发布或操作真实服务。

验证：字段回填、选择文件取消、切换入口/模式、缺省端口、未知字段与注释保留、非法值、并发修改、端口同步回归及四主题布局。
