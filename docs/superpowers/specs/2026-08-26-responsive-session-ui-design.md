# 局域网 Codex 会话整体自适应设计

## 目标

让局域网共享 Codex 会话页面在手机、平板、笔记本和宽屏桌面上自动适配。窗口缩放、横竖屏切换、打开文件预览、输入框增高和处理状态变化都不能造成整页横向滚动、顶部控件被挤出或内容被固定区域遮挡。

## 适配策略

采用视口断点与聊天主区域容器查询相结合的方式：

- 视口断点负责页面级结构，包括侧边栏、文件预览呈现方式和移动端视口高度。
- 容器查询负责顶部栏内部控件，根据聊天主区域的真实剩余宽度收缩，而不是只依赖浏览器总宽度。
- 消息内容、代码、表格和长路径在自身容器中换行或滚动，不把宽度压力传递到页面外层。

不创建单独的移动端页面，不引入 JavaScript 宽度监听或第三方响应式依赖。

## 断点与布局行为

### 宽屏：`≥ 1200px`

- 左侧任务栏固定显示，宽度沿用现有桌面规格。
- 默认聊天区占满剩余空间。
- 打开文件预览后使用右侧分栏；预览宽度在最小可读宽度和最大 `760px` 之间自适应。
- 聊天正文保持最大可读宽度并居中，不随超宽显示器无限拉长。

### 平板与窄笔记本：`821–1199px`

- 左侧任务栏继续固定显示。
- 文件预览不再参与 Grid 分栏，改为固定在右侧的覆盖式抽屉，宽度限制为视口可用宽度和合理最大值。
- 抽屉出现时聊天主区域宽度不变化，关闭后不需要恢复 Grid 列宽。
- 顶部栏通过容器查询压缩 Session、模型和连接状态文本，必要时隐藏次要标签。

### 手机与窄屏：`≤ 820px`

- 左侧任务栏变为从左侧滑出的抽屉，通过已有菜单按钮和遮罩开关。
- 主聊天区固定为 `100dvh`，顶部栏、消息时间线和输入区保持三行 Grid。
- 文件预览覆盖完整视口，不与聊天区并排。
- 顶部栏允许分成标题行和操作行；工作区路径隐藏，Session 和模型控件缩短。
- 消息区、输入区和处理状态横向间距缩小，但保留触控目标尺寸。

### 超窄屏：`320–520px`

- 页面左右间距进一步收紧，输入区占满可用宽度。
- `321–520px` 的历史图片保持两列；`≤ 360px` 改为单列，避免缩略图过窄。
- 处理状态文字允许省略，主状态仍可读。
- 文件预览和图片灯箱的关闭按钮保持至少 `44px`。

## 组件适配规则

### 顶部栏

- 标题和路径容器必须允许收缩并使用省略号。
- Session、模型、连接状态和菜单按钮保持稳定点击区域，不因文字长度扩张页面。
- 主区域宽度不足时依次隐藏工作区路径、控件说明文字和连接状态文字，最后才换为两行。

### 消息时间线

- 用户消息、Codex 回复、过程卡片和图片画廊最大宽度不超过容器。
- Markdown 表格外包横向滚动区域；代码块在自身内部滚动。
- 长路径、长 URL 和连续字符使用安全断行或局部滚动。
- 时间线继续保留独立纵向滚动，不让 `body` 承担会话滚动。

### 输入区与处理状态

- 输入框增长只压缩消息时间线，不扩大页面高度。
- 处理状态、附件预览和输入框共享相同内容宽度与响应式边距。
- “回到最新消息”按钮始终位于消息区内，并保持在输入区上方。
- 使用 `env(safe-area-inset-bottom)` 为移动设备底部安全区域留出空间。

### 文件预览

- 宽屏使用 Grid 分栏。
- `821–1199px` 使用右侧覆盖抽屉，层级高于聊天区，低于图片灯箱。
- `≤820px` 使用全屏覆盖。
- 代码、Markdown、图片和 PDF 都只能在预览体内部滚动。
- 打开和关闭预览不得改变页面或主聊天区的滚动偏移。

### 图片与灯箱

- 历史图片宽度不超过消息容器，保持比例。
- 灯箱使用 `100dvh` 和安全视口边距，横竖屏切换后仍完整展示图片。
- 灯箱层级始终高于侧边栏、文件预览、处理状态和回底按钮。

## 无障碍与交互

- 响应式隐藏只移除次要可见标签，不删除控件的可访问名称。
- 所有图标按钮保留可见焦点样式。
- 手机端交互按钮保持至少 `44×44px` 的触控区域。
- `prefers-reduced-motion` 下关闭非必要动画和强制平滑滚动。
- 高对比度模式继续使用现有语义色变量。

## 验证矩阵

浏览器验证以下视口宽度，允许高度根据典型设备设置：

- `320px`：最小支持宽度，单列图片、无整页横向滚动。
- `375px`：常见手机，侧边栏抽屉、两行顶部栏、输入区与灯箱正常。
- `414px`：大屏手机，双列图片和触控间距正常。
- `768px`：平板竖屏，移动结构和全屏文件预览正常。
- `1024px`：平板横屏/窄笔记本，固定侧边栏和覆盖式文件抽屉正常。
- `1440px`：标准桌面，文件分栏和聊天正文宽度正常。
- `1920px`：宽屏，内容不被过度拉长。

每个关键尺寸检查：

- `html`、`body`、应用外壳的 `scrollWidth` 不大于视口宽度。
- 顶部栏控件完整可操作。
- 消息时间线独立滚动。
- 输入框增高与处理状态出现时不遮挡消息。
- 文件预览打开和关闭后布局可恢复。
- 图片灯箱完整覆盖且图片不溢出。

## 测试与回归

- 静态测试确认关键断点、容器查询、安全区域和局部溢出规则存在。
- JavaScript 语法检查和全量 Python 测试通过。
- 使用真实局域网页面逐项完成验证矩阵。
- 不启动或重启桥接器、PHP/webman 服务；静态资源由现有服务直接读取，页面刷新后生效。

## 非目标

- 不改变当前深色视觉主题。
- 不重新设计信息架构、模型设置或会话切换流程。
- 不增加独立移动端代码仓库。
- 不调整后端接口、Session 数据、权限或队列逻辑。
