# 会话消息区“回到底部”悬浮按钮设计

## 目标

为局域网共享 Codex 会话的消息时间线增加一个“回到底部”悬浮按钮。用户浏览较早消息时，可以一次点击平滑回到最新消息；位于底部时按钮自动隐藏，避免长期遮挡内容。

## 交互设计

- 按钮位于消息时间线底部中央，悬浮在消息内容之上、输入区域之上。
- 当时间线距离底部超过约 `160px` 时显示；进入阈值范围后隐藏。
- 点击按钮后调用时间线自身的平滑滚动，目标位置为 `timeline.scrollHeight`。
- 平滑滚动过程中，按钮随滚动位置更新并在抵达底部后隐藏。
- 系统启用 `prefers-reduced-motion: reduce` 时使用立即滚动，不强制动画。
- 切换 Session、重新渲染历史、新消息流式更新后，都重新计算按钮显隐。
- 打开右侧文件预览时，按钮仍限定在聊天主区域内，不进入或遮挡文件预览区。

## 结构与样式

- 在消息时间线元素内部增加原生 `button`，避免额外的定位容器影响现有三行 Grid 布局。
- 使用项目已有的向下 SVG 图标体系，不引入新依赖。
- 按钮采用圆形、深色半透明表面、边框和轻量阴影，与当前 Codex 深色界面保持一致。
- 使用 `aria-label="回到最新消息"`，保留现有全局键盘焦点样式。
- 隐藏状态使用 `hidden`，不占据布局空间，也不进入键盘 Tab 顺序。

## 状态与数据流

1. 监听 `timeline` 的 `scroll` 事件并计算剩余距离：`scrollHeight - scrollTop - clientHeight`。
2. 剩余距离大于阈值时显示按钮，否则隐藏。
3. 点击后根据减少动态效果偏好选择 `smooth` 或 `auto` 滚动。
4. 时间线内容替换、自动跟随到底部或保留原滚动位置后，统一同步按钮状态。

显隐计算只依赖当前 DOM 滚动数据，不增加后端状态，不影响多用户实时同步。

## 边界处理

- 空会话或内容不足一屏时始终隐藏。
- 流式回复增长时，如果用户停留在历史位置，按钮保持显示；如果用户原本跟随底部，继续自动跟随且按钮隐藏。
- 快速重复点击不会创建队列或定时器，只更新浏览器原生滚动目标。
- 文件预览关闭后的布局恢复逻辑与该按钮互不修改对方的滚动容器。

## 验证

- 静态测试确认按钮结构、可访问名称、显隐同步函数和点击处理存在。
- JavaScript 语法检查通过。
- 全量 Python 测试通过。
- 浏览器验证：向上滚动后按钮显示；点击后平滑返回底部并隐藏；打开和关闭文件预览后位置正常；窄屏不遮挡输入框。

## 非目标

- 不显示未读消息数量。
- 不改变现有新消息自动跟随策略。
- 不增加“回到顶部”按钮。
- 不修改后端、Session 数据或桥接器启动方式。
