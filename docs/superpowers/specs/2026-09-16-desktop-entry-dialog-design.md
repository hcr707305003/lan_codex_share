# 桌面端口入口与停止确认样式

日期：2026-09-16。书面规格已确认，当前分支实现和验证完成；未提交、打包或发布。

## 服务入口

保持现有深色三卡片结构。Share 卡片显示 LAN 配置监听端口及本地 HTTP 打开入口；frpc 卡片显示 frpc 配置的服务端控制端口和 TCP 代理 localPort → remotePort 映射；Cloudflare 卡片显示回源 Share 端口和已配置公网域名。未知数据提示未配置，不能猜测服务已连通。

只有 LAN 配置中的合法 HTTP/HTTPS 入口可点击：frp_origin 对应 frpc，cloudflare_origin 对应 Cloudflare。兼容旧 public_origin，HTTPS 按 Cloudflare 入口展示，HTTP 按 FRP 入口展示并注明旧配置。不把任意 TCP 代理端口猜成网页；未配置 frp_origin 时明确提示配置后可打开。不解析/显示 token，不将控制端口当浏览器业务地址，不自动打开浏览器。

从配置生成入口，不解析进程命令或日志。路径和端口标签支持换行，多个代理限制卡片摘要长度，完整映射放在提示文本。配置修改后刷新入口，注明配置值可能需要服务重启生效，公网可达性未验证。入口读取不放进每 250ms 的 UI 刷新循环；点击时仅打开当前展示的、已验证方案为 HTTP/HTTPS 的地址。

## 停止确认

新增统一自定义 QDialog，沿用应用深色背景、边框、字体与间距。标题区突出服务名；正文区说明停止影响；可选详情区显示 PID/配置位置，长路径可换行。底部右对齐“取消”和“停止服务”或“强制关闭”按钮，危险按钮使用低饱和红色，默认焦点和默认按钮均为取消。

普通停止说明连接或任务可能中断，不联动其他服务；强制关闭强调跳过正常清理，保留现有精确进程校验。点击关闭叉、Esc 和默认 Enter 都取消。仅确认后执行原有停止逻辑，弹窗不能自行管理进程。不新增外部隧道停止权限。

统一适用于单服务停止、超时强制停止、外部 Share 强制关闭和“停止本客户端服务并退出”。其他信息、配置编辑和下载弹窗不做无关改动。

## 验证

单元测试验证来源映射、缺失/无效配置、HTTP/HTTPS 限制、控制端口与业务端口区分；Qt 测试模拟浏览器打开和停止回调，验证默认取消、Esc、明确确认及窗口边界。900/1280 宽度离屏截图检查卡片与弹窗。只使用模拟服务，不启停现有服务。当前分支修改，不提交、打包发布。
