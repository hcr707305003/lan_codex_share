# 右侧预览面板拖动宽度

## 目标与已确认方案

预览面板左侧增加分隔线，向左拖动放大、向右拖动缩小；双击恢复默认宽度；仅在当前浏览器记忆宽度。适用于所有使用该面板的文件预览，不修改文档解析或后端接口。

## 布局与交互

- 视口宽度至少 1200px：保持三栏布局。预览最小 360px，最大为视口宽度减去实际侧栏宽度和 360px 聊天区。默认沿用现有 45vw、最高 760px、最低 420px，并受上述边界约束。
- 821–1199px：保留现有浮层布局，支持拖动；最小 360px，最大为视口减去侧栏宽度，默认最高 640px。
- 820px 及以下：维持全屏预览，不显示拖动控件，不覆盖保存的桌面宽度。
- 分隔线具有约 10px 命中区，悬停和聚焦时高亮，显示左右调整光标。键盘可聚焦，左右方向键每次调整 20px，Home 恢复默认；提供 separator 角色、方向及当前宽度信息。
- 使用 Pointer Events 与指针捕获；拖动期间禁用文本选择，防止 PDF 等内容吞掉移动事件。释放、取消、窗口失焦、关闭面板时均清理拖动状态。
- 拖动不重新加载文件，不改变表格工作表和预览滚动位置；浏览器窗口变化时重新约束宽度，不能撑出横向页面滚动。

## 状态与安全

独立小型前端模块管理尺寸边界、指针交互和 localStorage。只保存有效的正数像素宽度；存储不可用或值无效时退回默认，不影响预览。关闭再打开或切换文件沿用偏好；双击/Home 清除偏好。窗口临时缩小只约束显示，不改写用户偏好。

沿用现有 CSS 与静态资源机制，保持 CSP，不增加 unsafe-inline。尺寸变更通过 CSP 兼容的 DOM 样式属性机制实现并在实际浏览器验证。不得因实现拖动放宽脚本/样式安全策略。

## 验收

自动测试覆盖宽度上下限、默认值、非法存储、存储失败、指针取消、键盘重置；浏览器测试覆盖宽屏拖动、刷新后记忆、双击恢复、浮层布局、375px 全屏以及关闭后聊天布局恢复。验证拖动时不重发文件请求，表格不撑开页面；既有前端测试与静态资源测试通过。

## 范围

仅在当前分支修改 lan_codex_share 的预览交互。保留尚未提交的 XLSX 类型兼容修复；不推送、不打包、不发布、不启动或重启用户服务。

## 规格自检

已明确各响应式区间、尺寸边界、交互清理、存储故障回退与验收范围；不增加全屏切换按钮、后端配置或其他无关功能。
