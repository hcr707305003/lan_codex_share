# Web 任务结束常驻提示

日期：2026-09-16

## 目标与已确认方案

在现有 Web 聊天页右下角显示非阻塞的任务结束提示卡片，必须由用户点击关闭，不自动消失。不使用居中阻塞弹窗或需要浏览器授权的系统通知。仅修改 lan_codex_share，保留当前分支已有改动，不提交、打包或发布，不操作现有服务。

备选方案为居中确认弹窗、浏览器系统通知；前者打断输入，后者依赖浏览器权限且在 HTTP 局域网环境有兼容限制，因此采用页面内常驻卡片。

## 配置

在 lan_config.toml 顶层新增：

```toml
# 当前 Web 会话的任务结束提示，需手动关闭；默认关闭
notify_on_task_complete = false
```

缺省为 false，严格接受 TOML 布尔值，字符串或数字报配置错误。示例配置和 README 说明开启方式、作用范围及服务重启后刷新页面生效；不擅自修改真实配置。通过现有页面启动配置或认证状态响应传递这一布尔值，不暴露其他配置内容。

## 桌面控制台配置（用户追加）

在控制台「配置管理」的 Share 配置表单增加“任务结束提示”开关，默认不勾选。辅助说明为“网页任务结束后显示常驻提示，需手动关闭；重启 Share 并刷新网页后生效”。

开关与 lan_config.toml 顶层 notify_on_task_complete 同源，不另存桌面专用副本。打开或重新加载配置读取当前值；表单保存写入布尔值，并沿用现有配置校验、保留其他字段和修改提示机制。原始 TOML 编辑器修改后重新加载表单应反映新值。仅操作开关不自动保存，也不自动重启服务；切换页面及未保存修改提示沿用现有规则。外观沿用控制台四套主题的现有控件样式。

## 追加：预览目录选择列表

用户选择目录列表而不是数组输入框：Share 表单的 preview_roots 改为有限高度的目录列表，逐项显示路径，可选中后删除，通过“添加目录…”打开系统目录选择器逐次添加。添加或删除仅更新未保存表单，继续使用现有“校验并保存”和放弃修改确认。

原始 TOML 仍可直接编辑数组，加载列表保留原有路径字符串与顺序。新增目录以配置文件所在目录为基准，优先生成带正斜杠的相对路径；不同磁盘无法计算相对路径时保存绝对路径。不改变工作目录或扩大预览权限到未选择路径。取消选择不改变表单；按 resolve 后的路径去重（Windows 大小写不敏感）；删除只移除配置项，不删除磁盘文件。列表可为空。无法识别的非字符串数组报格式错误，不悄悄覆盖。

该组件独立放在 desktop/directory_list.py，通过 changed(list[str]) 信号接入原有 updates 字典。测试覆盖追加、取消、重复、删除、空列表、相对路径基准、保存重载、非字符串拒绝和配置保存前文件未变。

## 追加：FRP 外部进程确认关闭

用户要求 FRP 支持开启和关闭，并授权不在场时按推荐方案完成。本客户端启动的 FRP 保持现有停止/超时强制停止功能；之前外部 FRP 无论是否匹配都禁用按钮，是本次补齐的缺口。

仅当检测到单个、可读取身份且配置路径匹配当前 frpc.toml 的普通外部 FRP 进程，显示“关闭外部 FRP…”；点击后使用现有主题确认弹窗、默认取消，说明将中断对应公网入口但不关闭 Share。执行前重新验证 PID、创建时间、程序路径、命令行和解析后的配置路径；只终止这个进程，不递归杀子进程。多实例、权限不足、身份变化、Windows 服务管理的实例均拒绝，提示使用服务管理器等原有入口操作。Cloudflare 的外部停止权限不扩大。

关闭由后台工作线程执行，操作期间禁用重复点击/启动和退出，结果后重新检测；外部扫描旧结果不得覆盖关闭后的新状态。关闭后允许现有启动流程重新启动当前配置。退出控制台不自动关闭外部 FRP。本轮仅测试模拟进程，不实际操作正在运行的 FRP。

## 提示行为

- 开启后，当前查看的 Session 的一次 turn 结束生成一条通知，使用真实 turn 状态区分“任务已完成”“任务失败”“任务已中断”。取消执行归入中断；排队消息被删除不算任务结束。
- 卡片只显示会话名称、结果和结束时间（服务端有时间则采用服务端时间，否则使用观察时间）；错误详情仍在原有聊天/错误提示处查看，不复制长输出或敏感内容。
- 卡片有明确的 × 关闭按钮和可访问名称，只有主动点击该按钮才移除，不抢焦点，不因点击聊天区、后续任务启动或计时而关闭。
- 多个未关闭通知保留在有限高度、内部可滚动的通知区域，不无限堆叠占满窗口；窄屏适配，避开输入框主要操作区。不保存到服务器或跨浏览器同步关闭状态。
- 多人同时查看同一 Session，各浏览器独立提示、独立关闭。
- 切换 Session 时清空旧 Session 卡片并建立新基线；刷新页面同样重新建立基线。仅在网页打开且已登录时工作，不承诺网页关闭后的提醒。

## 状态判断与接入

复用现有 snapshot/delta SSE 和补偿刷新，不增加轮询连接。独立的前端状态跟踪模块按 Session ID + turn ID 去重；界面模块负责卡片的安全文本渲染和关闭操作。

首次有效快照作为基线：所有已经结束的 turn 不通知，正在执行的 turn 进入观察集合。后续当前快照中已观察任务从非结束状态变为明确结束状态时提示；首次基线之后出现的新 turn 若直接以结束状态到达，也生成一次提示，以覆盖快速任务。正常数据增量和重复快照不会重复提示。

短暂断线不清空已有观察/去重状态；重连快照中仍包含的已观察任务若结束，只提示一次。连接中断、Session 释放、队列清空、页面从 processing 变 idle 本身不当作完成。无法获得明确结束状态时不猜测。历史分页加载不进入通知跟踪器，因此向上加载更早记录不会补弹。切换 Session 的过期网络响应沿用现有 generation 检查丢弃。

不扩大历史快照窗口，不为通知拉取全部历史；长时间断线且任务已离开当前历史窗口时，不补查这些完成事件。未进入正式 turn 的提交失败继续使用原有错误提示。

## 验收与验证

1. 缺省和 false 无卡片；true 生效；错误配置类型有明确错误。
2. 历史任务不弹；运行中任务完成、失败、中断分别提示；快速新任务结束能提示。
3. 重复快照、SSE 增量及重连不重复；断线/释放不伪装完成；加载历史不触发。
4. 连续任务的未关闭卡片保留，逐个关闭互不影响；当前 Session 切换后不串通知。
5. 多浏览器独立状态；键盘可操作关闭按钮；状态区域使用适合非阻塞通知的 aria-live，不抢输入焦点；标题等通过 textContent 渲染。
6. 使用隔离配置及模拟状态测试，不停止或重启现有 Share、隧道或 PHP 服务；补充自动化测试并运行相关回归，检查桌面与窄屏布局。
7. 控制台开关缺省关闭；加载 true/false、勾选保存、取消勾选保存及原始配置重新加载一致；保存不影响其他字段、不触发服务启停，保存失败不误报成功。
