# 工作目录选择器

用户要求工作目录改成选文件夹，沿用此前允许自主采用推荐方案的约定，当前 main 开发。

采用只读可复制路径栏 +「选择文件夹…」原生目录对话框；保留原始 TOML 编辑。相比继续手填增加了路径选择校验，相比仅按钮仍能直接看清配置值。

- 优先从当前工作目录打开；当前目录无效时从配置文件所在目录打开。
- 新路径相对 lan_config.toml 所在目录保存，跨盘保存绝对路径，正斜杠编码；不依赖进程工作目录。
- 旧值未操作保持原样。取消、同一目录选择不标记修改。无效目录报错并保留旧值。
- 选中后仅修改表单；显式校验并保存才写盘，沿用外部文件修改检测和原子保存。
- 不自动启动、停止或重启任何服务。不改其他字段、不改变 Session 语义。
- 沿用四套主题，路径宽度自适应、完整路径可复制并通过悬浮提示查看。
- 测试选择、取消、同目录、中文/空格、跨盘、缺失目录、保存和原始编辑往返；离屏截图验证；生成独立本地包，不覆盖旧包/私人配置，不提交或发布。

自审：仅单目录控件和配置表单接线，无新依赖，无后台服务或权限扩展。
