# 会话顶部折叠项目公告

日期：2026-09-29
状态：用户已确认交互方案，书面规格待审阅。

## 目标与范围

已设置公共公告的项目，其下所有共享 Session 在会话标题下方显示「项目公告」。复用项目资料存储和接口，不增加会话级公告，不改变 AI 上下文、鉴权或真实项目文件。不发布、打包或重启现有服务。

## 已选交互

- 使用会话内折叠栏，而非仅增加跳转右侧的按钮，方便直接阅读。
- 只有当前会话所属项目存在非空白公告时显示。未分配项目、公告为空或被删除时不占空间。
- 初次打开、刷新以及切换 Session 后默认收起，包括同项目会话之间切换。不持久化展开状态。
- 收起时只显示「项目公告」与展开指示，不展示正文。点击展开呈现安全 Markdown，支持既有链接、列表和表格。
- 展开正文最大高度为 min(280px, 35dvh)，超出独立滚动；手机宽屏和窄屏均不撑出页面，保留聊天与输入框可用空间。
- 公告栏保留「编辑」入口，打开现有右侧项目资料面板并进入编辑状态；仍遵循未保存修改确认和保存期间禁止切换的保护。
- 项目资料更新时，不强制展开或收起。已展开则更新正文；被清空时隐藏并重置状态。

## 数据与实现边界

- 使用快照中的当前 Session → 项目映射，不根据显示别名匹配项目。
- 快照继续只携带 has_notice/revision，不附带公告全文。has_notice 按去除首尾空白后的正文判断，与界面展示条件一致。
- 收起时不读取全文；展开时通过现有认证 GET /api/projects/profile 获取，按项目 ID 和 revision 缓存，版本变化使旧正文失效。
- 切换会话立即清空旧公告并使未完成请求失效，迟到响应不能覆盖新会话公告。展开期间重复快照不重复发请求。
- 加载失败显示简短错误与重试按钮，不阻止聊天；失败后不因每次快照自动重试。
- 复用安全 Markdown 渲染器和本地文件预览权限，原始 HTML 不执行、危险协议不生成链接，不请求远程图片。
- 为主面板增加独立 auto 公告行，聊天行仍为 minmax(0, 1fr)。展开收起不修改会话历史 DOM、不触发历史加载、不主动滚动到顶部；在底部跟随与阅读旧消息场景分别验证。
- 展开按钮提供 aria-expanded/aria-controls，加载结果提供状态提示，键盘可操作。沿用现有配色、字号和聚焦样式。
