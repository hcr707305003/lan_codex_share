# 长会话按需加载

用户已批准：首屏最近 20 轮，上滑接近顶部自动加载更早 20 轮，无需正常加载按钮；流式局部更新；工具过程展开后加载；图片懒加载；保留阅读位置、全部历史和后台任务。本次不发布版本。

## 数据边界

HTTP 快照默认分页，内部完整 projection 保留兼容。先切片再复制；页面快照只包含用户问题、最终回复、过程数量及轮次版本，不包含工具正文和 Diff。历史游标使用 projection 世代和数组位置，追加新轮次不会移动旧游标，重新同步后旧游标拒绝并提示刷新。

过程接口按 turn ID 和同一世代读取，每批 20 个过程项（含 Diff），最近过程优先；正在执行时更新当前过程页。全部接口沿用 Session 白名单、项目密码及 Host 验证，不向浏览器发送原始隐藏推理。

## 浏览器

按 turn ID、版本复用节点。加载旧消息前记下可见消息位置，前插后补偿高度，不强制跳到底部；只有原本靠近底部时跟随回复。每个 Session 切换清空缓存、终止旧请求并拒绝过期结果。无变化快照不重绘。SSE 更新合并，避免高频拉取堆积。

滚动距离顶部不超过 80px 时自动请求，加载中合并重复触发，失败暂停自动请求并提供可键盘操作的重试按钮。历史越翻越多时允许用户回到最近 20 轮释放已加载旧内容；不做完整虚拟列表，单个超长回复仍受现有文本上限限制。服务端仍在首次恢复 Session 时读取完整记录，本次解决浏览器传输和渲染开销。

## 验证

用 2000 轮合成数据验证首屏 20 轮、游标无重复遗漏、追加及重同步、工具延迟加载、稳定 DOM、滚动锚点、切换竞态、图片懒加载和移动宽度。运行 Python/Node 回归，隔离浏览器验证不触碰真实任务或业务服务。
