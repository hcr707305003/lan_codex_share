# 桌面组件默认路径自动匹配

日期：2026-09-16。状态：书面规格已获确认，已实现并通过 386 项回归测试；未打包发布。

## 范围

仅调整桌面客户端 frpc、cloudflared 的可执行文件发现与路径保存。沿用现有服务管理、下载器和启动方式；不修改业务项目，不操作现有服务，不打包或发布。

采用固定默认位置发现，而不是全盘扫描或新增用户可配置搜索目录。

## 发现规则

- 有效的手动指定路径始终优先，不因发现新版本而替换。
- 未指定路径时，检查客户端程序目录、LAN 配置文件目录、两者的 bin 及其版本子目录，最后查询系统 PATH；重复目录和同一文件去重。
- 程序目录沿用现有 distribution_directory 定义，不使用启动命令的当前工作目录。源码模式为项目根目录，打包模式为分发目录。
- 根目录只检查直接子文件；bin 内最多向下三层，不遍历整个项目，不跟随目录链接或目录联接；设扫描数量上限，避免异常目录拖慢界面。
- 自动匹配标准 frpc/cloudflared 名称，以及符合当前操作系统与 CPU 架构的官方平台后缀名称；不匹配安装器、压缩包、其他架构或服务端 frps。Unix 下须具有执行权限。
- 自动发现仅有一个本地候选时直接展示为可用；有多个本地候选时列出完整路径，用户选择后保存，不擅自挑选最新版。没有本地候选时使用 PATH 的首个有效命中。
- 手动指定路径失效时明确提示，重新扫描可提供候选，但不静默覆盖原配置；用户重新选择后才更新。

## 界面和保存

- 保留“选择本地程序”，增加“重新扫描”；启动界面时执行一次发现，后续可手动刷新，无须重启客户端。
- 展示实际命中路径和未找到、路径失效、多候选待选择等状态。
- 扫描只读取目录和文件属性，不执行候选文件，不启动连接；版本检测仍由用户单独触发。扫描不阻塞界面，不在状态刷新定时器中重复遍历目录。
- 配置目录下的程序（包括下载到 bin/frp 的程序）保存相对于配置目录的路径，以支持整包移动；配置目录之外的手动选择保存绝对路径，避免引入新的配置字段。
- 下载完成后复用相同的路径保存与界面刷新逻辑。正在运行的进程不因重新匹配而切换程序。

## 验证

单元测试覆盖目录去重、版本子目录、平台文件名、非可执行文件、扫描边界、手动优先及失效、多候选、PATH 后备和相对路径迁移。Qt 离屏测试覆盖重新扫描和选择后状态更新，确保没有启动服务。运行现有桌面测试及项目回归测试；本次不重新制作安装包。
