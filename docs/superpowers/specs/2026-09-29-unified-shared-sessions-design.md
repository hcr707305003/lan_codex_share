# 共享会话统一配置与移出释放

日期：2026-09-29
状态：已确认并实施；通过自动化测试和隔离双页面交互验证。

## 已确认目标

共享名单统一由当前启动参数指定的 `lan_config.toml` 管理，不另建 YAML 配置。网页添加已有会话或新建会话后写回同一文件的 `session_ids`；“移出共享”同时释放占用、删除该配置项和左侧任务。不删除、归档真实 Codex 会话，不删除历史、附件或项目公告。

## 模式与兼容

- 增加 `session_mode`：`selected` 为指定列表、`all` 为自动发现全部、`auto` 为自动单会话。显式模式优先。
- `selected` 下 `session_ids = []` 表示零个共享任务，页面仍可添加会话，不回退为自动创建或共享全部。
- 未配置模式的旧文件维持原行为：非空数组是指定列表，空数组是全部，缺失字段是自动单会话；兼容旧 `session_id`。
- 在 `all` 或 `auto` 模式下首次通过网页增删共享项时，提示将当前共享名单固定为 `selected`，确认后才写入。移除一个任务不能让自动发现立即把它加回来；不引入另一份排除名单。
- 控制台表单保存上述明确模式，保持三个模式的用户含义；原始文件编辑仍可用。

## 新增与移出流程

- 新增已有会话先验证元信息，按 ID 去重，成功保存配置后再向所有浏览器广播。创建新会话继续保留创建请求幂等记录；如果会话已创建但配置保存失败，提示真实 ID，重试只完成共享登记，不重复创建。
- 移出前确认文案明确“释放占用并取消共享，保留历史”。执行中或有排队消息时拒绝，不自动取消任务。
- 操作期间对该会话阻止新提交及重新连接，保证检查空闲到释放之间没有竞态。未加载的会话不为移除而加载。
- 校验配置可写和版本，释放占用，再原子保存名单，最后从 Hub 移除并广播。释放失败不修改名单；释放成功但保存失败时保留任务为已释放状态，显示失败原因并允许重试，不假报成功或自动重新占用。
- 当前浏览器及其他浏览器正在查看被移出项时，切换到可用任务；无剩余任务时显示空状态。保留未发送草稿，不把草稿自动发送到其他会话。
- 保留旧释放接口的解除占用语义以兼容旧客户端；新界面统一使用明确的移出接口，不把旧接口悄悄升级为删除名单。

## 配置保存与旧数据

- 配置文件是唯一共享名单来源，运行数据只保存幂等请求、缓存、历史等，不再通过 `shared_sessions.json` 的名单持续补入会话。
- 旧运行文件有额外共享 ID 时提供一次性导入提示：确认才合并进配置；取消则仅按配置加载。原文件保留，迁移完成标记仅在成功写入后记录，避免静默丢失或重复导入。
- 使用保留注释的 TOML 编辑和原子替换，仅修改模式及会话字段；不改密码、路径、端口和隧道配置。
- 网页与桌面保存使用同一个无 UI 依赖的配置写入边界，提供跨进程写入协调和版本检查。读取最新版本后应用名单差异；检测到未协调的外部编辑时拒绝覆盖并提示重载。
- 网页操作保存成功立即更新运行状态；控制台或手工修改仍沿用“保存不自动重启”的行为，不在本次增加全配置热加载。
- 配置错误、只读、冲突和磁盘写入失败都显示简短可操作提示，不输出配置内容或密钥。

## 验证与范围

- 单元测试覆盖旧配置兼容、三种模式、空名单、去重、注释保留、失败不覆盖、并发保存。
- 会话测试覆盖忙碌拒绝、移除提交竞态、未加载移除、释放失败、保存失败保留已释放状态、重复请求、创建后保存失败重试。
- 重启恢复只读配置，旧名单不能复活已移出项；测试一次性导入与取消导入。
- 浏览器验证多人同步、当前项移除、最后一项移除、草稿保留、新任务重新添加。
- 只使用临时配置和模拟会话，不修改真实配置，不操作正在运行的服务，不推送、不打包、不发布。

## 自查
