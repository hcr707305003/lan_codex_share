# ZIP 内文件浏览与预览

## 目标与范围

用户已同意推荐方案：从聊天中的 ZIP 文件链接打开右侧面板，浏览包内目录、预览文件、下载单个文件或原始整包。不改变聊天、会话管理及上传类型范围；本次处理工作区或 preview_roots 中的 ZIP，不新增 ZIP 上传入口。

保留当前未提交的下载修复，作为本功能的基础。仅在 lan_codex_share 当前分支开发；不操作任何运行中的服务，不自动推送、打包或发布。

## 交互

- 复用右侧文件面板与现有主题。打开 ZIP 时展示当前目录的文件夹、文件名、未压缩大小；文件夹排在文件前，同类按名称排序。
- 目录面包屑支持返回上级，进入成员预览后可返回目录。每页最多 100 个条目，避免一次性构造几千个 DOM 节点。
- 顶部始终有「下载整个 ZIP」入口；成员有独立下载入口，避免把单个文件和整包下载混淆。
- 文件名、目录名、表格值一律作为不可信文本显示。长名称可换行，不撑开面板；窄屏仍可使用现有预览面板。
- 更换文件、关闭面板或切换会话时取消旧请求，迟到响应不能覆盖当前预览；清理已生成的对象 URL。
- 不支持预览的成员明确显示「不支持在线预览，可下载原文件」，不显示空白页。

## 支持格式

- Markdown 使用现有安全渲染器；代码、TXT、CSV 以文本显示，HTML/SVG 不作为可执行页面加载。
- PNG、JPEG、GIF、WebP、BMP 显示图片；PDF 使用现有内嵌预览方式并保留下载入口。
- DOCX 提取正文和表格文字，复用现有受限文档提取逻辑，不还原完整排版；旧 DOC 仅下载。
- XLSX 按工作表显示只读表格；只读取已保存的单元格值，不计算公式、不执行宏、不获取外部链接。无缓存结果的公式单元格给出提示，不把空缓存当成计算结果。
- 每次仅渲染选中的工作表，最多前 200 行、50 列，明确标注截断及完整文件下载入口。不承诺合并单元格、图表、图片或原版样式还原。
- 旧 XLS、XLSM、其他二进制以及嵌套 ZIP 仅提供成员下载，不递归展开。RAR、7z、分卷和加密 ZIP 暂不支持浏览。

## 后端与数据流

1. WorkspaceFileViewer 负责真实路径解析和授权目录校验，继续复用下载与预览分离的入口。
2. 新增独立 ZIP 读取模块，负责目录元信息、成员标识、安全校验和按需读取，不使用 extractall，不将 ZIP 内路径拼接到磁盘。
3. 新增只读目录、成员预览和成员下载接口，由 lan_web 路由调用；所有请求先执行现有 Host、登录及授权目录校验，不能只在首次打开 ZIP 时检查。
4. 成员以中央目录索引标识，响应包含包的版本标记，后续请求校验该标记。包被替换或修改时返回冲突提示并要求刷新，不在旧索引下返回另一个成员。
5. 预览响应使用结构化 JSON 或限定的图片/PDF MIME。成员下载强制 attachment、nosniff，并正确编码中文文件名；下载原始 ZIP 沿用现有分块下载接口。
6. 文档解析使用隔离子进程，复杂解析及 ZIP 目录读取也必须有超时和内存约束，不能长期占住 HTTP 工作线程。所需临时文件只使用系统生成的独立路径并在完成、失败、超时后清理。
7. XLSX 可引入固定版本的读取依赖，但需在实施阶段验证 API、依赖和五平台 PyInstaller 收集；不引入 Office 或系统解压命令依赖。

## 安全与资源限制

- 可浏览 ZIP 大小最多 200 MiB、中央目录最多 8 MiB、最多 5,000 条目、路径深度最多 32 层；在构造完整条目列表前先限制输入及中央目录规模。
- ZIP 声明的总未压缩大小最多 500 MiB，单成员最多 25 MiB、压缩比最多 100:1。声明值和实际读取字节数都检查；文本预览最多 2 MiB，DOCX 文本继续使用现有 100,000 字符上限。
- XLSX/DOCX 自身也是 ZIP，必须检查内部条目数、未压缩总量和压缩比；不能仅凭外层成员大小判断安全。
- 拒绝绝对路径、盘符、UNC、包含 .. 的路径、NUL、软链接及特殊文件成员；同时处理反斜杠。重复或规范化冲突的成员名拒绝操作，避免歧义。
- 每次解析最多 30 秒、子进程内存最多 512 MiB；并发解析最多 2 个，繁忙时立即返回可重试提示，不形成无界队列。
- 单个成员下载也经过限额、CRC 和路径检查；被拒绝或超限的包仍可下载原始 ZIP，原始整包下载不进行解压。
- 不运行 ZIP 中的脚本、宏、可执行文件，不递归解包，不跟随文档外部资源。MD 中的包内链接本期不自动展开，沿用现有安全链接策略。

## 异常处理

损坏包、CRC 错误、加密、未知压缩算法、超限、繁忙及超时均显示明确中文提示；不暴露服务端堆栈。未授权、越界、文件不存在、包版本变化分别使用现有错误约定或明确的 401/403/404/409 状态。ZIP 浏览失败不得禁用合法授权文件的整包下载。

## 验收

- 含多级企业目录和多个 XLSX 的 ZIP 能逐层浏览、切换工作表，下载得到与原始成员完全一致的字节。
- MD、代码、中文名、图片、PDF、DOCX 各自预览正常；不支持的类型可下载；空包、空目录、空表有清晰提示。
- 验证路径穿越、软链接、同名前缀目录越界、重复成员、加密、损坏、炸弹包、嵌套 Office 包炸弹、条目超限、超时和并发限制。
- 验证登录保护、动态 preview_roots、ZIP 修改后旧引用失效、关闭面板后迟到响应无效、返回目录及整包/成员下载不串文件。
- 验证超大工作表不会一次性创建巨量 DOM、公式不计算、外部链接不请求，现有普通文件和上传附件预览无回归。
- 运行针对性 Python/JS 测试及全量回归；发布前追加冻结程序的 ZIP/Office 解析冒烟测试。本次不自动发布。

## 规格自检

范围限定为工作区 ZIP；预览和原包下载限额分开；旧 Office、嵌套包、宏与公式处理已明确；不修改服务启动配置，不包含待定项。
