# 发送框上方消息队列面板实施计划

## 1. 页面结构

- 在发送框区域新增可隐藏的队列面板、实时数量、列表和清空按钮。
- 从更多菜单移除清空入口，保留取消当前任务入口。

## 2. 前端渲染

- 将 `snapshot.pending` 渲染为紧凑 FIFO 队列项。
- 保留现有单条取消和批量清空 API。
- 从聊天时间线移除排队消息渲染，开始执行后继续使用真实 Session 历史。

## 3. 样式与响应式

- 队列列表设置最大高度和独立滚动。
- 为长文字、图片消息和窄屏布局提供稳定的截断与触控区域。
- 复用现有颜色、边框和减少动画规则。
