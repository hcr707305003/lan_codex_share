# 流水线发布文档与功能型 Release Notes 实施计划

## 1. 版本说明校验

- 新增 `scripts/check_release_notes.py`，验证标签格式、对应文件、标题和至少一个非空功能分类。
- 新增单元测试，覆盖有效说明、缺失文件、标题不匹配和空功能分类。

## 2. 发布流水线

- 标签构建阶段校验 `docs/releases/vX.Y.Z.md`。
- Release 创建或重试时使用该文件同步 GitHub Release 正文。
- 保留五平台构建、冒烟测试、ZIP 和 SHA-256 生成逻辑。

## 3. 维护者文档

- 新增 `PIPELINE_RELEASE.md`，完整说明首次配置、日常验证、版本准备、标签发布、产物验收、失败重试和回滚。
- 更新 `README.md`，增加维护者入口。
- 新增 `docs/releases/v0.1.1.md`，仅记录相对 `v0.1.0` 的用户可感知功能变化。

## 4. 验证与交付

- 运行测试、Python 编译检查、JavaScript 语法检查和 Git 差异检查。
- 提交并推送主分支，确认主分支流水线通过。
- 使用新版本说明更新现有 `v0.1.1` Release，并核验正文与发布资产。
