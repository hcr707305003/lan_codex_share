# 控制台 Session 列表配置

日期：2026-09-17

## 目标与范围

用户已确认采用列表管理，替代控制台 Share 配置中的 Session JSON 单行输入框。保留现有后端配置含义、原始 TOML 编辑、校验保存和未保存修改保护。不新增会话发现、连接或删除功能；不自动启动/重启服务，不修改真实配置，不提交、打包或发布，在当前分支保留已有改动。

备选方案为一行一个 ID 的多行文本框；实现较小，但列表的选中、复制与移除更明确，因此采用已确认的列表方案。复用现有主题与预览目录列表风格，不另设计整体界面。

## 三种模式

| 控制台模式 | 配置含义 | 保存结果 |
| --- | --- | --- |
| 指定会话 | 只共享列表中的 Session | 非空 `session_ids = ["id-a", "id-b"]` |
| 共享全部 | 发现本机所有未归档主会话，按项目分组 | `session_ids = []` |
| 自动单会话 | 复用已保存的自动会话，没有时由原有启动流程创建 | 不设置 `session_ids` 和 `session_id` |

模式选择旁显示当前模式说明。“共享全部”明确提示会扩大共享范围，不由删空列表或粘贴空内容自动选中。

载入时根据配置区分缺省、空数组及非空数组，不默认覆盖现有模式。旧 `session_id` 非空映射到指定会话，空字符串映射到自动单会话；仅修改其他配置时保留旧格式，明确编辑 Session 设置后才迁移为上表规范格式并移除旧字段。新旧字段同时存在或字段类型错误时提示错误，不猜测或静默覆盖。

## 列表与批量输入

- 指定会话模式显示限高可滚动列表，每个 ID 一行，保留顺序，选中后可以复制 ID 或移除。
- 列表下方提供输入区及“添加”按钮。可输入单个 ID、换行/逗号分隔的一组 ID，或粘贴现有 JSON 字符串数组。
- 添加时去掉首尾空白、忽略分隔产生的空项，按完整 ID 去重并保留首次出现顺序。JSON 非字符串成员、损坏的数组或 ID 内部空白报错，保持原列表与输入草稿，不部分添加。
- 不新增固定 UUID 版本限制，不改变后端当前接受非空 ID 字符串的约定；不通过网络核实 ID 是否存在。
- 添加成功后清空输入区；全为空的输入不改变列表或模式。显示已配置条数及简短的重复项提示。
- “复制 ID”只在用户点击时写入剪贴板；没有选中项时复制、移除不可用。移除不删除真实 Session 或其历史。
- 删除最后一项后仍为指定会话模式，显示“请至少添加一个 Session，或主动切换共享模式”，禁止保存为空数组。不能因此变成共享全部。
- 未点击添加的非空输入算未保存草稿，保存或切回原始配置时提示先添加或清空，避免丢失或静默提交。
- 本次不提供自动扫描本机会话、会话标题查询、全选本机任务或清除真实任务等操作。

## 保存与控件状态

独立 Session 列表控件负责模式、列表、批量解析、输入校验与变更通知；ConfigPage 负责接入已有未保存状态和应用表单。ConfigDocument 仅增加明确移除指定配置字段的能力，以支持自动单会话及旧字段迁移，不将 None 普遍解释为删除。

切换模式不会立即写文件。指定会话列表草稿可在本次表单编辑期间保留，切回指定会话时恢复；选择其他模式后仅按该模式保存，重新加载以实际配置为准。模式切换时非空批量输入仍必须先处理，不静默丢弃。

所有更改只有点击“校验并保存”才落盘；继续保留其他 TOML 字段及注释、检测外部文件修改，保存失败保留草稿。重新加载、原始 TOML 与表单切换反映实际配置，不改变 `session_ids` 缺省与空数组的区别。原始编辑仍遵循现有后端校验。

小窗口沿用表单内部滚动，保存按钮保持可见；列表和批量输入区限高。四套主题、可访问标签、键盘选择/复制按钮均适配。

## 验收

1. 三模式分别往返加载/保存，缺省不意外成为空数组；旧格式只在显式 Session 编辑时迁移。
2. 添加单个、批量换行/逗号、JSON 数组，去空格、去重；非法输入整体拒绝，草稿保留。
3. 复制和移除仅影响指定项；删空列表不能保存为共享全部；空输入不改变模式。
4. 未添加输入、未保存模式/列表变化触发现有丢弃保护；取消丢弃不丢失输入。
5. 保存失败不误报成功、不重启服务；配置原始编辑与重载一致，不触发任何会话连接或删除。
6. 隔离配置与 Qt 自动化测试覆盖以上行为；检查 900×640 布局和四主题，运行现有完整回归。
