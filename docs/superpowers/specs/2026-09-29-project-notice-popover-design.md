# 项目公告顶部浮层设计

日期：2026-09-29
状态：用户已确认书面规格，已实施。

## 目标

将现有占据独立行的公告栏改成标题旁的紧凑「项目公告」入口。只调整 Web 展示和交互，不修改公告存储、接口、权限或会话行为，不打包、发布或操作运行中的服务。

## 布局与样式

- 入口放在会话标题旁，有非空公告才显示；使用线性图标、文字和展开指示，保持低对比背景、细边框和圆角。
- 默认收起；展开为非模态浮层，不占主面板网格高度，不改变聊天滚动位置。
- 浮层采用现有主题颜色，包含标题、关闭按钮、Markdown 正文和底部「编辑公告」。收起时隐藏编辑入口。
- 桌面浮层宽度最多 420px，定位在入口下方；以主面板可用边界约束位置，不能覆盖左侧导航或越出屏幕。
- 手机端左右至少保留 12px，正文限高并独立滚动。窗口缩放、右侧文件面板开合时重新约束浮层位置。
- 公告和其他顶部菜单避免同时叠加；无全屏遮罩，不锁定页面滚动。

## 交互和状态

- 点入口切换展开，点浮层外部、关闭按钮或按 Esc 收起。浮层内部选择文字、滚动、点击链接不触发外部关闭。
- 关闭按钮及 Esc 关闭后焦点返回入口；鼠标点外部关闭不抢占目标焦点。键盘可访问正文链接和编辑按钮。
- 使用 aria-expanded、aria-controls 表达展开状态，关闭按钮具有可访问名称。
- 编辑公告先通过现有项目资料面板的未保存保护；成功打开编辑面板后收起公告。
- 初次进入、刷新、切换 Session 后默认收起。公告变更保留当前展开状态；被删除时隐藏入口及浮层。
- 保留已有懒加载、缓存、取消请求、迟到响应隔离、失败重试逻辑，收起不额外请求全文。
- Markdown 继续使用现有安全渲染器；不增加 HTML 执行或远程图片加载能力。

## 实现范围

- `web/index.html`：移动入口，增加浮层容器、标题及关闭按钮。
- `web/style.css`：移除独立公告行，增加浮层布局、主题及响应式约束。
- `web/notice.js`：补充关闭、焦点和定位管理；保持原有请求与状态接口。
- `web/app.js`：接入新增元素和与其他菜单协调的必要回调。
- `tests/javascript/notice.test.cjs`：扩展交互及状态回归。
- `README.md`：更新公告使用说明。
