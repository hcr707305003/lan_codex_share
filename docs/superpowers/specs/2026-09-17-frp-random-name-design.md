# FRP 随机代理名称

用户在本地包测试中追加要求：frpc 配置 name 随机生成，避免多客户端默认 codex-share 重名。按此前自动采用推荐方案约定实现。

- 新建 FRP 示例时才生成 `codex-share-<uuid4 hex>`；不硬编码用户名、IP 或机器名。UUID 提供极低全局碰撞概率，不承诺未经服务器查询的绝对唯一。
- FRP 表单显示只读可复制代理名称和「重新生成」按钮。明确点击才为选中 TCP 代理生成新名称；检查同份配置内其他名称避免碰撞。
- 已有名称加载、普通保存、重启均保持原样。生成仅改草稿，保存后才写文件；下拉选项反映当前代理名。
- 不连接 frps，不改公网端口或认证，不重启任何服务；文档提示名称不同不代表公网端口可复用。
- 测试新建示例两次不同、保存后稳定、选中代理修改隔离、本文件内碰撞重试、取消未保存修改。
- 和工作目录选择器一起产出独立本地测试包，不覆盖旧包、不推送发布。

自审：不会通过自动改名影响已有运行配置，无新依赖，原始编辑可手动命名。
