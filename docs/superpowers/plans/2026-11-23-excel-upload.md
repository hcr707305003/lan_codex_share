# Excel 上传实现计划

目标：发送框接受 XLSX / XLS，Codex 收到各工作表的单元格文字，附件支持工作表预览与原文件下载。

实施：
- 复用现有 XLSX 解析代码到 spreadsheet_reader.py；补充 xlrd 读取 XLS；不执行公式、宏或访问外部链接。
- 上传检查覆盖所有工作表，沿用单文件 20 MiB 及隔离解析限制；Excel 不因文字总量拒收，每份提供至多 20,000 字符的明确节选、完整工作表目录及原文件本机路径，Codex 按需读取整表。其他文档保留文字上限。
- 预览复用现有 spreadsheet JSON / 表格组件，维持每表 200 行、50 列，切换表不改变下载地址。
- 更新前后端白名单、依赖和 README；测试真实文件上传、模型输入、跨会话权限、下载与切表。

不重启现有服务，不修改真实会话，不发布版本。

验证：47 项文档上传、提取、预览与消息回归通过；含五份超过 100,000 字符的大表上传、原始字节保留和重启后路径恢复。
