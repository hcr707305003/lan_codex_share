# v0.5.2

## 新增功能

- 网页右上角「⋯ → 重命名」支持修改当前会话名称，直接写回 Codex，并同步共享列表及会话标题。
- 支持 1～100 个字符的名称校验；保存失败保留输入，保存期间阻止重复提交，切换会话不会改变已打开弹窗的目标。

## 行为或兼容性变化

- 重命名仅更新名称，不改变 Session ID、历史、共享名单或消息队列。
- 名称刷新与重命名串行处理，避免在途旧目录结果覆盖新名称；不占用 Hub 全局锁等待远程请求。
- 沿用项目登录和 CSRF 校验。所有有权访问 Share 的用户均可重命名共享会话；旧版 Codex 不支持该接口时会提示升级。

## 升级提示

- 提供 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 五个平台版本包，包含桌面控制台及 Share/CLI。
- 保留现有配置和 runtime 数据，手动退出旧程序并启动新版本，再刷新网页。源码用户需自行重启 Share。
- README 截图沿用 v0.5.1 演示图，新增入口以本版功能为准。
