# v0.4.3

## 功能修复

- 修复多个 Session 同时执行时通知串会话的问题：另一个会话的开始通知不再覆盖当前会话的任务状态，当前任务完成后，其排队消息可以继续执行，无需等待其他会话结束。
- 按 Session ID 隔离任务通知、回复及模型设置，避免共享 App Server 的其他会话事件影响当前会话；同一会话内仍按队列顺序执行。
- 修复在 Codex 中重命名会话后，网页侧栏、会话标题和项目分组内名称未同步的问题。默认约 5 秒刷新名称，已打开的多个客户端同步更新。
- 名称同步只刷新元信息，不重新加载整段历史、不重启会话；名称查询暂时失败时保留最后一次成功获取的名称。

## 行为或兼容性变化

- 固定共享列表也会同步会话名称，但不会自动加入未共享的会话或改变共享范围。
- 共享 App Server 中无法确认所属 Session 的任务通知将被忽略；独立 stdio 连接保留旧版无 Session ID 通知的兼容处理。

## 升级提示

- 提供 Windows x64、Linux x64/ARM64、macOS x64/ARM64 五个平台包，包含 Share/CLI 和桌面控制台；仍需本机安装并登录 Codex CLI。
- 本次为服务端修复，需要手动重启 Share 后生效。先等待正在执行的任务结束，并处理好尚未执行的排队消息，再升级重启；不要覆盖正在运行的程序文件。
- 保留私人配置和完整 `runtime/`，不要用示例配置覆盖已有配置。
- Windows 包未代码签名、macOS 包未公证，请核对下载包与 `SHA256SUMS.txt`。
