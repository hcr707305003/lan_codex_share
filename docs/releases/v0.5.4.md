# v0.5.4

## 新增功能

- 模型菜单预设 GPT-6.1 Sol、GPT-6 Astra、GPT-6 Sol、GPT-6 Luna、GPT-5.6 Sol、GPT-6.1 Terra、GPT-5.6 Terra、GPT-5.6 Luna、GPT-5.5，按此顺序显示。
- 模型设置新增「自定义新增模型」：填写模型 ID 和显示名称后保存，重启仍保留；新增不会自动切换会话，需选择后应用。
- 自定义列表保存在 Share runtime 下的 custom_models.json，由同一服务的会话共享；最多支持 100 个自定义条目，拒绝重复 ID。

## 行为或兼容性变化

- 不提供加载缓存列表按钮，也不将本地预设宣称为 Codex 桌面端实时列表。
- 上游已返回的同名模型保留实际能力信息，其余上游模型继续追加显示；本地预设或自定义项是否可调用由账号及上游服务决定。
- 新增模型入口沿用登录、CSRF 及共享会话校验。所有能访问 Share 的用户均可添加模型。

## 升级提示

- 提供 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 五个平台版本包，包含桌面控制台和 Share/CLI。
- 保留配置及 runtime 数据，待当前任务结束后自行退出旧程序并启动新版，再刷新网页；仅刷新网页不会更新后端模型列表。
