# v0.6.1

## 新增功能

- 支持上传常用源码（CSS、JS/TS、JSX/TSX、Vue、Python、Java、Go、PHP、Shell、PowerShell）、配置和数据（JSON、YAML/YML、TOML、XML、CSV、SQL）、LOG、SVG。
- 支持 ZIP、TAR.GZ 项目包上传，保留完整原包和目录结构，预览文件目录，供 Codex 按需读取，不自动解压到项目目录或执行包内代码。
- 发送框支持选择或拖入 HTML、HTM 附件，可与问题、图片及其他文档一起发送。
- HTML 附件支持右侧完整源码预览与原文件下载，保留标签、样式和脚本源码；预览不会执行脚本或加载外部资源。

## 功能修复

- 源码、配置、数据及文本附件不超过 100,000 字符时直接提供完整内容；超过后自动切换为原文件方式，向 Codex 提供完整文件路径并要求读取文件。不截取源码，不因字符数超限拒绝上传，也不要求手动拆分。
- 自动切换后，网页预览和下载仍保留完整内容；服务重启后附件关联及原文件路径保持有效。

## 升级提示

- 等待任务结束后退出旧 Share，替换程序并启动新版，再刷新网页；保留配置与 runtime 数据。
- 新增附件格式沿用现有文件大小、数量及会话访问权限设置。文本使用 UTF-8、带 BOM 的 UTF-16 或 GB18030；原文件保存在 Share 主机，Codex 通过现有文件工具和权限读取。
- 提供 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 五个平台包，包含桌面控制台及 Share/CLI。
