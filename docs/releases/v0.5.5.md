# v0.5.5

## 功能修复

- 消息中用反引号包裹的完整 Windows 文件路径现在可点击，在右侧预览并使用现有下载按钮下载原文件。
- 支持中文、空格及行号形式的路径，例如 `C:/project/My Report.md:1`；历史消息重新渲染后同样生效。
- 普通命令、代码块和非文件代码文本保持原样，不扩大服务端预览目录的访问权限。

## 升级提示

- 提供 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 五个平台版本包，包含桌面控制台和 Share/CLI。
- 保留配置及 runtime 数据，待当前任务结束后自行退出旧程序并启动新版，再刷新网页。
- 本次只修改网页渲染逻辑；源码用户更新代码后刷新网页即可。
