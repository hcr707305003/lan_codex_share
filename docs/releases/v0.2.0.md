# v0.2.0

## 新增功能

### 桌面控制台与统一应用图标

- Windows、macOS、Linux 的版本包现在同时提供桌面控制台和原有 Share/CLI 程序，无需安装 Python。Windows 双击 `lan_codex_desktop.exe`，macOS 打开 `LAN Codex Share.app`，Linux 运行 `./lan_codex_desktop`。
- 服务总览可分别启动和停止 Share、frpc、Cloudflare，查看各服务状态、PID、本地端口及公网入口，并点击打开网页。启动控制台或 Share 不会自动启动隧道。
- 可以识别外部启动的 Share 与隧道进程。外部 Share 和明确匹配当前配置的单个外部 FRP 普通进程，可在二次确认后关闭；外部 Cloudflare、Windows 隧道服务和无法确定归属的进程只读显示，不自动接管。
- 提供石墨薄荷、暖白森林、午夜蓝、柔和紫四套主题，配置页和确认弹窗统一换肤，外观选择保存在本机。应用窗口与发行包使用统一图标。
- 日志支持按服务筛选、搜索、暂停显示及导出。暂停日志显示不会暂停服务。

### 可视化配置管理

- Share、frpc TOML 和 Cloudflare YAML 支持表单与高级文本编辑模式。字段下方展示配置键名、用途和注意事项；保存前校验，保留未编辑字段及注释，并检测文件是否被外部改动。
- 工作目录可选择文件夹；预览目录可逐项添加、移除和去重。目录选择只改变草稿，移除不会删除磁盘文件。
- Session 共享范围提供“指定会话”“共享全部”“自动单会话”。指定会话可批量粘贴 ID、复制和移除；不会因列表删空而意外扩大为共享全部，也不会删除真实会话历史。
- FRP 新建示例使用随机代理名称，可手动重新生成；“应用 Share 端口”只更新当前 TCP 代理的本地端口草稿，不改公网端口、控制端口或其他代理。
- Cloudflare 表单可选择凭证 JSON 文件、编辑 Tunnel 和域名、应用 Share 回源地址，并切换已有 HTTP(S) 入口规则。复杂 YAML 仍可通过高级模式编辑；Token 模式的远程配置不会被本地 YAML 覆盖。
- 保存 Share 端口变化时，尝试同步明确匹配原端口的 FRP 和本地 Cloudflare 回源；保存隧道配置时，可推导并同步对应 Share 公网入口。存在多个候选或已有不同入口时会先提示选择，不覆盖无关服务配置。

### FRP 与 Cloudflare 双公网入口

- 新增 FRP 公网 IP＋端口入口，同一 Share Web 端口可同时被 frpc 和 Cloudflare Tunnel 映射，也可只配置其中一个或全部关闭。
- `frp_origin` 与 `cloudflare_origin` 独立配置，共享会话、任务队列和项目密码。同一公网入口下仍可通过 `/proxy/localhost:端口/` 访问其他可信本地服务，无需为每个服务增加公网端口。
- 组件管理支持扫描默认安装路径、选择已有程序，以及从 GitHub 官方 Releases 获取最新稳定版 frpc。按平台架构匹配下载、核验官方摘要后安装到程序目录下，下载完成不会自动连接服务；也可跳转官方下载页。
- Cloudflare 支持本地 YAML 和 Token 文件两种启动模式，Token 内容不直接放在启动命令参数中。

### 网页任务结束提示

- 新增 `notify_on_task_complete` 配置及控制台开关，默认关闭。开启后，任务结束会在网页显示需要手动关闭的常驻提示；不同浏览器独立关闭，初次载入历史不会补弹旧提示。

## 功能修复

- 修复配置字段说明受下拉框、复选框宽度限制而换行截断的问题，说明随表单宽度自动排版。
- 修复切换 Session 共享范围后预览目录区域塌陷，造成列表、添加/移除按钮、说明及相邻输入行相互遮挡的问题；滚动、窗口缩放和高级编辑往返后仍保持正常布局。
- 修正外部启动服务在控制台被误认为已停止的显示；进程运行与公网连通状态分开表达，检测到进程不等于已经验证公网可达。
- 配置入口同步后更新卡片跳转链接，FRP 控制端口、本地端口和公网业务端口分别展示，避免混用。

## 行为或兼容性变化

- 仍需在本机安装并登录上游 Codex CLI；版本包不包含 Codex 登录凭证，也不内置 frpc/cloudflared 二进制。Linux 桌面程序需要图形桌面环境。
- 窗口启动、组件下载、配置保存都不会自动启停服务。配置更改影响运行中服务时，需手动重启相应服务；退出时仅按确认结果处理控制台自行启动的进程。
- FRP 的 HTTP 公网入口要求非空项目密码，但浏览器到公网服务器仍是明文 HTTP。frp TLS 仅保护 frpc/frps 链路，敏感用途应使用专属 HTTPS 入口。动态反代只应接入可信服务。
- 旧 `public_origin` 可继续单独使用；改用 `cloudflare_origin` / `frp_origin` 时须移除旧字段，不能混用。Cloudflare Token 模式的回源需要在 Cloudflare 控制台调整。
- Windows 包未进行代码签名，macOS 包未公证。各平台下载文件提供 SHA-256 校验值，请按系统安全提示核验来源。

## 升级提示

- 请先等待正在执行的任务结束，备份 `lan_config.toml`、隧道配置及 `runtime/`，再手动停止旧程序并解压新版。保留 `runtime/lan/auth.json` 可延续已有有效登录，不要用示例覆盖私人配置。
- 桌面包包含配套依赖目录或 `.app`，应完整解压，不要只复制桌面可执行文件。默认配置在发行目录，macOS 在 `.app` 外侧；也可用 `--config=路径` 指定现有配置。
- 升级后重新启动所需服务并刷新网页。任务结束提示默认不开启，需要在配置中显式开启。
- 不要公开项目密码、FRP Token、Tunnel 凭证、原始配置截图或运行日志。源码与版本包只包含示例配置。
