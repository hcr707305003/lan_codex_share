# v0.4.0

## 新增功能

### 新任务与共享会话管理

- 网页「新任务」支持从已有会话列表中搜索、选择并加入共享，也可以选择已有项目工作目录创建新 Session，不再只能通过顶部下拉切换。
- 网页添加或创建会话后，将 ID 保存到当前启动配置文件的 `session_ids`，左侧共享任务与配置统一管理，服务重启后仍保留。
- 「移出共享并释放」会释放会话占用，同时删除配置名单中的 ID 和左侧任务；不会删除或归档真实 Codex 会话，也不会删除历史、附件和项目公告。
- 会话正在执行或仍有排队消息时禁止移出；释放失败不修改配置。若释放成功但配置保存失败，保留已释放条目供重试，不自动重新占用。
- 多个浏览器同步共享列表变化；当前会话被移除后切换到剩余会话，无剩余会话则显示空列表。各会话未发送草稿独立保留，不串到其他会话。

### 项目别名与 Markdown 公告

- 支持给项目设置便于识别的别名，以及共享的 Markdown 公告，用来记录项目用途、相关网站和操作说明。
- 对应会话顶部提供紧凑的项目公告入口，默认收起；展开浮层查看，不长期占用聊天区域。项目内会话共用同一份说明。

## 功能修复

- 修复部分 POST 请求被提前拒绝后，未读取的请求体与下一条 GET 拼接，导致浏览器收到 `501 Unsupported method` 的问题。
- 修复切换会话后未稳定定位到最新消息：进入时自动置底，图片等内容延迟改变高度时继续跟随；主动上滑阅读历史后不再强制拉回。
- 修复释放会话时 WebSocket 关闭握手与读取线程争用，导致移除操作及其他实时快照请求阻塞的问题。关闭连接不再依赖对端回应关闭握手。
- 修复会话移除成功后，SSE 使用刚失效的会话 ID 读取快照而报「指定的 Session 不在共享列表中」的问题；并发读取会正常回退到剩余会话或空列表。

## 行为或兼容性变化

- 新增明确的 `session_mode`：`selected` 使用指定名单、`all` 自动发现全部、`auto` 自动单会话。`selected` 下的 `session_ids = []` 表示不共享任何会话，仍可通过新任务添加。
- 未配置 `session_mode` 的旧文件保持原规则：非空数组为指定会话、空数组为全部会话、缺失字段为自动单会话。
- 在 `all` 或 `auto` 模式下通过网页增删共享项，会先要求确认将当前名单固定为 `selected`，避免移出的任务被自动发现重新加入。
- 旧运行时共享名单不再自动与配置合并；提供一次性的导入或跳过确认。创建操作仍保留重试记录，配置保存失败后不会因同一次重试重复创建会话。
- 配置更新保留其他字段和注释，并增加原子写入、保存冲突检测。控制台或手工编辑的配置仍需手动重启服务生效，不新增自动重启。
- 旧 `/api/session/release` 接口保留仅释放语义；新版网页使用移出共享接口。

## 升级提示

- 发布包继续包含 Share/CLI 与桌面控制台，提供 Windows x64、Linux x64/ARM64、macOS x64/ARM64 五个平台；仍需本机安装并登录上游 Codex CLI。
- 等待正在执行的任务结束，备份私人配置与完整 `runtime/`，再手动停止旧程序、解压新版并启动。不要用示例配置覆盖现有配置。
- 源码用户需在实际运行环境执行 `python -m pip install -r requirements.txt`，本版核心依赖增加了保留 TOML 注释的配置编辑支持。
- 升级后手动重启 Share，并刷新所有已打开的网页，以使用新的移除接口与滚动逻辑。
- Windows 包未代码签名，macOS 包未公证；请核对 Release 中的 `SHA256SUMS.txt`。
