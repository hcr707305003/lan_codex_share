# v0.1.2

## 新增功能

- 支持通过配置项 `password` 为共享网页设置访问密码；留空时保持原有的免登录行为。
- 密码启用后，Session、消息、实时进度、图片和文件接口统一受登录保护，多人仍可在登录后查看同一任务的实时状态。
- 登录使用浏览器会话 Cookie，共享程序重启后旧登录自动失效；连续输错密码会触发短时频率限制。
- 支持在网页中主动释放空闲 Session，让 Codex CLI/App 重新接管；需要继续网页操作时可再手动连接。
- 排队消息移到输入框上方展示，可取消单条尚未开始的消息，也可一次清空全部待处理消息。

## 功能修复

- 修复网页切换 Session 后，已离开的空闲 Session 仍被共享程序占用、导致本机 Codex 客户端无法打开的问题。
- 修复浏览器刷新、关闭或网络中断时，Windows 偶发输出完整 `WinError 10053` 请求堆栈的问题；这类预期断开现在只记录一条简洁日志，不影响后台任务继续执行。

## 行为或兼容性变化

- 新增 `password = ""` 配置，默认值为空，因此现有配置升级后仍可直接访问，无需输入密码。
- 只能释放当前空闲且没有排队消息的 Session；释放后不会自动重连，以免再次占用本机会话。
- 默认局域网 HTTP 不加密传输内容和密码。密码功能用于访问控制，不替代 HTTPS 或可信网络隔离。

## 升级提示

- 如需启用登录，在 `lan_config.toml` 中设置非空的 `password`，然后手动重启共享程序。
- 启用密码后，已打开的浏览器页面会显示登录界面；共享程序重启也会要求重新登录。
- 原有 `workspace`、`session_ids`、权限和端口配置无需迁移。
