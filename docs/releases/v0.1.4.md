# v0.1.4

## 模型兼容性

- 网页模型选择器新增 GPT-6 Astra，使用真实请求 ID `gpt-6-astra`。当旧版 Codex App Server 的模型目录尚未包含 Astra 时，共享服务会补充兼容条目，方便在已有上游访问权限的情况下选择使用。
- 兼容条目支持 low、medium、high、xhigh、max、ultra 六档思考强度，以及默认和 Fast（priority）速度。调整设置后会同步到共享该 Session 的页面，并用于后续任务；不会自动切换现有会话的模型。
- 如果 App Server 已返回 Astra，则直接使用其模型名称、默认值和能力列表，不重复添加兼容条目，也不覆盖服务端支持的思考强度或速度。

## 升级提示

- 配置文件无需调整。替换程序后重新启动 LAN Codex Share，再刷新浏览器即可加载新增模型。
- 模型条目可选不代表当前账号或上游服务已开放调用权限；实际使用 GPT-6 Astra 仍需上游支持。本次验证覆盖模型目录、设置传递和页面接口，未进行真实 Astra 推理调用。
- 提供 Windows x64、Linux x64 / ARM64、macOS Intel / Apple Silicon 五个平台版本包。每个包内的同一程序继续支持 Share 和 CLI 子命令，以及 `--config` 指定配置。
