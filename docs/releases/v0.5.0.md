# v0.5.0

## 新增功能

### ZIP 压缩包浏览与成员预览

- 点击会话中的本地 ZIP 链接，在右侧逐层浏览目录，支持面包屑返回与分页，每页最多 100 项。
- 可分别下载整个压缩包或其中某个文件，不必先下载并解压整包。
- 包内 Markdown、代码、文本、图片、PDF 可直接预览；DOCX 展示提取的正文和表格文字，不还原 Word 原始排版。
- XLSX 支持切换工作表，展示前 200 行、50 列的已保存值。不会计算公式；缺少缓存值时明确提示。日期可能以原始数值显示，不还原格式、合并单元格和图表。
- 不支持在线预览的成员仍提供下载入口。压缩包变化后提示重新读取；关闭面板或切换文件会取消旧预览请求。

### 预览面板可拖动调整宽度

- 在桌面浏览器拖动右侧预览左边界：向左放大，向右缩小，方便查看宽表格和代码。
- 当前浏览器自动记忆宽度；双击分隔线恢复默认。分隔线获得焦点后可用左右方向键调整，Home 重置。
- 保留聊天区最小可用宽度；手机窄屏继续全屏预览。拖动不会重新加载文件，关闭预览后聊天区恢复正常宽度。

## 功能修复

- 修复 ZIP 等二进制文件链接无法正常下载的问题；不支持预览或 ZIP 浏览失败时仍可下载原包。
- 修复部分合法 XLSX 被误报为“不是有效的 XLSX 工作簿”的问题，兼容通过默认扩展名声明工作簿类型的导出文件，同时保留显式类型优先及宏文件限制。

## 范围与限制

- ZIP 浏览仅支持工作目录或 preview_roots 授权目录中的文件，沿用项目密码校验；不新增 ZIP 上传类型。
- 浏览上限为 200 MiB、5,000 个条目、32 层目录；单成员最多 25 MiB、声明总解压量最多 500 MiB、压缩比最多 100:1。文本预览最多 2 MiB，DOCX 最多 100,000 字符。
- 解析使用隔离进程，单次最多 30 秒并监测 512 MiB 内存上限，同时最多两个解析请求；繁忙时请稍后重试。不解压整包到工作区，不执行宏、公式或外部资源。
- RAR、7z、加密、多卷及 ZIP64 不支持浏览；旧版 DOC/XLS、XLSM、嵌套 ZIP 仅提供下载。

## 升级提示

- 版本包包含桌面控制台和 Share/CLI，提供 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 五个平台。
- 保留现有配置及 runtime 数据目录，退出旧程序后使用新版本启动，再刷新网页；无需修改配置或安装 Office。
- 源码用户更新后需手动重启 Share。预览和下载仍受授权目录限制，升级不会扩大文件访问范围。
