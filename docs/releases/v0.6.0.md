# v0.6.0

## 新增功能

- 当前会话支持多选删除历史记录：用户消息单独选择，“查看过程”和对应 Codex 回复合为一项，点击记录区域即可切换选择。
- 删除直接写回本机 Codex 原会话，保持 Session ID 不变，支持已经压缩过上下文的长会话。删除前保存备份，校验失败时恢复原历史文件和索引。
- 上传附件支持 XLSX、XLS，可预览单元格并切换工作表，下载保留完整原文件。

## 功能修复

- 修复长会话删除后原生历史索引未同步、导致校验失败的问题。
- 删除成功后，原先由 Share 接管的会话会自动重新接管；重新接管失败时单独提示，不把已经完成的删除显示为失败。原先已释放的会话保持释放状态。
- 修复 Excel 提取文字超过 100,000 字符时无法上传的问题。大表提供工作表目录、至多 20,000 字符的内容节选和完整原文件路径，Codex 可按需读取原文件，无需拆表。

## 行为或兼容性变化

- 原生历史删除目前仅开放已验证写锁兼容性的 Windows；其他系统保留其余功能。
- 删除已压缩的长会话记录时会重建上下文：其余原始历史仍可查看，后续任务使用保留的近期上下文，不保证完整旧历史继续进入模型上下文。
- Excel 读取保存的单元格值，不计算公式、不执行宏、不访问外部链接；预览每张表前 200 行、50 列。单文件默认 20 MiB 等上传大小和数量限制保留。

## 升级提示

- 等待任务结束后退出旧 Share，替换程序并启动新版，再刷新网页；保留配置和 runtime 数据。
- 删除会影响 Codex 原生历史，并非仅从网页隐藏。操作前确认所选内容；原生备份保存在 Codex 数据目录的 `history-edit-backups/`。
- 提供 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 五个平台包，包含桌面控制台及 Share/CLI。
