# v0.1.3

## 新增功能

- 右侧文件预览面板新增下载按钮，位于刷新和关闭之间。打开 Markdown、源代码、文本、图片或 PDF 后，可以直接保存当前文件，无需再到工作区手动查找。
- 下载文件保留原始文件名，支持中文、空格及其他非 ASCII 字符；桌面端使用紧凑图标，移动端提供 44px 触控区域。

## 行为与权限

- 下载只对已成功预览的当前文件开放。加载中、预览失败或关闭预览后，按钮自动禁用并清除旧文件地址，避免误下载上一个文件。
- 下载继续遵守 `workspace`、`preview_roots`、支持的文件类型、文件大小上限和可选访问密码，不会扩大局域网共享服务的文件读取范围。
- 下载完成或失败不会关闭、替换或清空当前文件预览。

## 升级提示

- 配置文件无需调整。升级程序后重新启动 LAN Codex Share 即可使用下载按钮。
