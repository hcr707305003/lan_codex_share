# v0.1.7

## 新增功能

- 长会话历史分页：首屏仅获取最近 20 轮完整问答，向上滚动接近顶部时自动加载更早 20 轮，无需点击加载按钮。全部历史仍保留，可逐页查看。
- 历史加载提供状态提示、重复请求拦截和失败重试；失败后暂停自动重试，避免持续请求。新增“回到最近 20 轮”，方便返回最新消息并释放已加载旧内容。
- 工具过程按需读取：展开“查看过程”才加载命令输出、思考摘要、工具结果和 Diff，每页 20 项，支持查看更早或最新过程；执行中的过程继续实时更新。

## 功能修复

- 修复长会话每次刷新都复制、传输完整历史，并在浏览器重建全部消息节点导致的严重卡顿。服务端先分页再复制，历史快照不再夹带折叠的工具正文。
- 流式回复按轮次版本及消息内容复用未变化的节点，合并高频刷新通知，减少重复渲染和请求堆积；图片继续懒加载并使用异步解码。
- 加载更早消息时补偿滚动位置，避免旧内容插入后阅读位置跳动；查看历史时不强制追随底部，仅靠近底部时跟随最新回复。
- 切换 Session、重置历史或登录失效时释放页面缓存并终止旧请求，防止迟到响应污染当前页面；折叠过程时释放已渲染工具正文。

## 行为或兼容性变化

- 浏览器首屏与历史页默认 20 轮，HTTP 快照接口 `limit` 允许 1–50；工具详情改由独立分页接口读取。直接消费旧版完整 HTTP 快照的自定义客户端需要适配分页元数据和游标。
- 持续跟随底部时，自动累积的页面轮次限制为 100；这只释放浏览器中的旧内容，不删除服务器历史。手动向上查看仍可加载更早记录。
- 分页游标在新增问答后仍可使用；重新同步整个历史后旧游标失效，刷新页面后重新翻页即可。新的读取接口继续受项目密码、Host 和共享 Session 范围约束，不展示隐藏的原始推理。
- 本次优化浏览器传输及渲染，不改变后台任务生命周期。服务端首次恢复 Session 仍读取完整记录，单条极长回复仍有渲染成本，不承诺所有大小的会话都恒定耗时。

## 升级提示

- 保留 `lan_config.toml` 和 `runtime/`，替换对应平台程序后重新启动共享服务，再刷新浏览器；仅刷新页面无法加载服务端分页改动。
- 不需要新增配置、修改或重启被代理的业务服务；共享服务本身的重启请安排在任务空闲时进行。
- Windows x64、Linux x64 / ARM64、macOS Intel / Apple Silicon 五个平台版本包继续包含 Share 和 CLI 入口，支持 `--config`，并提供 SHA-256 校验文件。
