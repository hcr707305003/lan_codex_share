# v0.4.1

本版包含原计划 v0.4.0 的全部更新，并补充公网入口图标。v0.4.0 打包发布已取消，升级请使用本版。

## 新增功能

- 左侧 Codex 标识右侧新增蓝色 FRP 通道图标和橙色 Cloudflare 云朵图标。已配置 `frp_origin` / `cloudflare_origin`，且检测到对应本机隧道进程运行时显示；停止后自动隐藏。
- 悬停查看公网地址，点击在新标签页打开并保留当前 Session。入口跟随会话切换更新，支持键盘操作和手机侧栏。
- 悬停说明和 README 补充 `/proxy/目标主机:端口/` 用法、前端 `#/login` 示例，以及 localhost 指向 Share 电脑的说明。
- 入口仅在通过项目密码认证后查询；不返回 Token、进程参数或配置路径。进程状态不等于配置匹配或公网可达，悬停提示明确说明，服务不会为了显示入口而自动启动隧道。
- 网页「新任务」支持搜索并加入已有 Session，或在已有项目目录创建新 Session；不再只能通过顶部下拉切换。
- 项目支持别名和共享 Markdown 公告，便于记录网站、用途和操作说明。会话顶部公告入口默认收起，点击浮层查看，同项目共用说明。

## 功能修复

- 修复拒绝 POST 后未消费的请求体与下一次 GET 拼接，导致 `501 Unsupported method` 的问题。
- 修复切换会话后未稳定置底；延迟加载内容改变高度时保持最新位置，主动上滑后不再强制拉回。
- 修复释放会话时 WebSocket 关闭握手阻塞读取线程，连带卡住会话管理及 SSE 快照的问题。
- 修复移除成功与实时快照并发时出现「指定的 Session 不在共享列表中」并中断增量流的问题。正常回退到剩余会话或空列表。

## 行为或兼容性变化

- 网页新建、添加、移出共享统一保存到当前 `lan_config.toml` 的 `session_ids`，保留其他字段和注释，并检测并发保存冲突。
- 「移出共享并释放」同时解除占用、移除配置项和左侧任务；不删除真实会话、历史、附件或项目公告。任务执行中或有排队消息时不可移出。
- 若释放失败，不修改名单；若释放成功但保存失败，保留已释放条目供重试。新建操作保留重试记录，避免同一请求重复创建。
- 多个浏览器同步名单变化，并按会话保留各自未发送草稿。
- 新增 `session_mode`：`selected` 指定名单、`all` 全部发现、`auto` 自动单会话；显式 `selected` 下空数组表示零个共享会话。旧配置未写模式时继续兼容旧行为。
- `all` / `auto` 模式通过网页增删共享项前，需要确认固定当前名单。旧运行时共享名单提供一次性导入或跳过，不再自动与配置合并。
- 旧 `/api/session/release` API 仍仅释放；新版网页使用移出共享接口。控制台或手工配置修改仍需手动重启生效。

## 升级提示

- 五平台包包含 Share/CLI 和桌面控制台：Windows x64、Linux x64/ARM64、macOS x64/ARM64。仍需本机安装并登录上游 Codex CLI。
- 等任务结束后备份私人配置及完整 `runtime/`，手动停止旧程序并换用新版；不要用示例覆盖私人配置。保留附件和认证运行数据。
- 源码用户在实际运行环境执行 `python -m pip install -r requirements.txt`，本版核心配置编辑新增 tomlkit 依赖。
- 手动重启 Share，并刷新已打开的网页。公网图标约每 10 秒更新一次；进程在其他机器或容器中、权限不足或状态无法判断时不显示。
- 当前只提供已配置地址的快捷入口，不验证进程配置确实映射当前 Share，也不验证公网连通性；原项目密码及访问限制保持不变。
- Windows 包未代码签名、macOS 包未公证，请核对 `SHA256SUMS.txt`。
