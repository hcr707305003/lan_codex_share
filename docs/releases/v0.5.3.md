# v0.5.3

## 新增功能

- 网页输入框上方的任务处理提示条新增「停止任务」按钮，无需打开右上角菜单即可停止当前会话正在执行的任务。
- 保留菜单中的取消入口，两个入口共用停止逻辑，并阻止重复提交。

## 行为或兼容性变化

- 点击时固定目标 Session，切换会话不会取消其他会话任务；停止请求不会清空排队消息，后续消息仍可继续执行。
- 发出停止请求后等待真实任务结束状态，不将请求成功当作已结束。

## 升级提示

- 提供 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 五个平台版本包，包含桌面控制台和 Share/CLI。
- 保留配置及 runtime 数据，自行退出旧程序并启动新版，再刷新网页。
- 本次不修改用户的超时配置；此前本机设置的 7200 秒不会写入公共版本包。
