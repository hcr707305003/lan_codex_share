# v0.5.1

## 功能修复

- 修复 ZIP 内 PDF 预览被页面 CSP 拦截的问题，显式允许同源及 blob 框架加载，保留其余安全限制。

## 行为或兼容性变化

- 精简 ZIP 预览工具栏，将返回目录、面包屑和下载入口放在同一区域；窄面板自动换行，长文件名省略显示。
- PDF 撑满预览面板剩余高度，移除顶部常驻提示。保留浏览器原生 PDF 阅读器、下载入口及无法内嵌时的提示。
- 保留预览面板拖动调宽功能；切回目录、Markdown 等文件时恢复普通内容滚动。

## 升级提示

- 提供包含桌面控制台和 Share/CLI 的 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 五个平台版本包。
- 保留现有配置及 runtime 数据，手动退出旧程序并启动新版本，再刷新网页。源码用户也需手动重启 Share，以加载 CSP 修复。
- 浏览器原生阅读器的工具栏和缩略图样式仍由浏览器管理。若 IDM 等下载扩展拦截 PDF 请求，需在扩展侧调整拦截设置。
- 本次不扩大文件访问范围，不新增渲染依赖。
