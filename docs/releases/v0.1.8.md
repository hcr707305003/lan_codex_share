# v0.1.8

## 新增功能

- 登录状态固定保留 30 天：成功登录后，重启共享程序或关闭浏览器不再要求重复输入项目密码。服务器验证凭证签名和到期时间，不因日常访问自动延长有效期。
- JS/CSS 内容指纹缓存：前端应用静态资源使用带 SHA-256 内容指纹的地址，支持长期缓存、ETag 校验和 HEAD 请求；文件变化后自动引用新地址，避免缓存旧代码而无法更新。
- 实时增量推送：SSE 首次发送最近 20 轮问答，之后直接推送变化字段、消息和追加文字。稳定连接期间无需每次通知后再 GET 整页快照，减少公网访问的重复传输和额外往返。

## 功能修复

- 修复服务重启导致所有浏览器登录立即失效的问题。签名密钥持久保存在配置旁的运行目录中，每次登录生成独立凭证，浏览器不保存密码明文。
- 修复已打开页面在服务重启后保留旧 CSRF 令牌、导致登录仍有效但发送请求失败的问题；连接恢复时同步当前令牌。
- 实时流断线后以新快照补齐期间发生的变化，不重复追加文字；切换 Session 时丢弃旧连接数据，防止串入其他会话。
- 文字更正、消息删除和历史重新同步可正确更新增量基线；保留历史上滑加载、过程按需展开及多浏览器实时同步。

## 行为或兼容性变化

- 修改项目密码并重启后旧登录凭证失效；以空密码启动后再启用密码，也会撤销之前的凭证。已建立的会话事件流在凭证过期后停止发送，并要求重新登录。
- Cookie 保留 HttpOnly、SameSite=Strict；公网 HTTPS 入口附加 Secure。局域网 HTTP 不提供传输加密，仅用于可信网络。
- 只有白名单中的前端应用 JS/CSS 允许公共缓存，首页、私有接口、图片、文件下载及反代内容仍不公共缓存。不要对整个分享域名设置“缓存所有内容”。Cloudflare 缓存命中仍取决于节点和已有规则。
- 旧版 SSE 更新通知接口仍兼容；历史和过程内容仍按需请求。缓存与增量优化不消除网络、TLS、Tunnel 链路或上游模型延迟。

## 升级提示

- 保留 `lan_config.toml` 和 `runtime/`，在任务空闲时替换对应平台程序、重启共享程序并刷新浏览器。已打开的页面不会被强制刷新。
- 从旧版本首次升级需要重新登录一次，后续保留 `runtime/lan/auth.json` 即可跨重启保留登录。密钥文件属于敏感数据，不要上传、分享或覆盖为其他实例的文件。
- 如需撤销全部登录，停止共享程序后删除 `runtime/lan/auth.json` 再启动，或修改密码后重启。清除浏览器 Cookie、无痕窗口关闭、切换域名或凭证满 30 天仍需重新登录。
- 无需新增配置，也无需重启被代理的其他业务服务。
- 提供 Windows x64、Linux x64 / ARM64、macOS Intel / Apple Silicon 五个平台版本包及 SHA-256 校验文件；每个包继续包含 Share 和 CLI 入口，支持 `--config` 指向配置。
