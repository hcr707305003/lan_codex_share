# v0.3.0

## 新增功能

### 文档附件上传

- 网页发送框支持通过回形针选择或拖拽上传 Markdown（MD）、TXT、Word（DOCX）和 PDF；可只发文档，也可将问题、图片和多个文档一起发送。图片原有的 Ctrl+V 粘贴方式保持不变。
- 文档以文件卡片显示名称、格式、大小和提取提示。AI 接收提取后的文字，无需在本机安装 Word；DOCX 提取正文段落和表格，PDF 按页提取可复制文字。
- 每条默认最多 5 个文档，单文档默认最多 20 MiB，文档总大小最多 100 MiB。新增 `max_documents`（1～20）和 `max_document_bytes`（1 字节～20 MiB）配置，未配置时使用默认值；文档与图片数量限制独立。公网穿透还可能限制整个请求大小。
- 上传失败会保留问题和附件供修改重试；发送过程中阻止重复提交。任一附件校验失败时整条消息不入队，不会只发送部分材料。

### 点击附件预览与原文件下载

- 点击已发送文件卡片中的文件名，在现有右侧预览栏查看内容；支持刷新、关闭与下载原文件。文件名支持键盘操作，手机窄屏使用适配后的预览布局。
- MD 显示标题、列表、表格和代码块等 Markdown 排版；TXT 显示纯文本；DOCX 显示提取的段落及表格文字，不保证还原原始版式；PDF 使用浏览器内嵌查看器，不支持内嵌的浏览器可下载查看。
- 刷新页面、切换 Session 或重新打开历史消息后，附件记录仍可恢复。之前上传且原文件仍存在的附件也可预览，首次打开可能需要重新解析。
- 预览与下载沿用项目密码、请求来源及 Session 范围校验；不公开服务器文件路径。Markdown/文字预览不执行上传材料中的 HTML、脚本或宏，也不自动加载远程图片。

## 行为与限制

- 每份文档最多提取 100,000 字符，每条文档合计最多 200,000 字符；超限会明确提示拆分，不静默截断。单文件解析最多 30 秒，同时只解析一个文件；繁忙时提示稍后重试。
- 旧版 `.doc` 需先另存为 `.docx`。不支持扫描 PDF 的 OCR、加密 PDF，以及文档图片、批注、修订和完整复杂排版的识别；图片内容仍可另行作为图片附件发送。
- 取消尚未开始的排队消息或清空队列时，只删除对应消息的附件；已开始/完成消息的原文件保留供历史查看。服务重启不恢复未执行的内存队列。
- 快速切换文件或关闭预览时，较早请求的结果不会覆盖当前面板。PDF 预览仅允许同源内嵌，其他页面及下载的嵌入限制保持不变。
- 原文件和预览缓存留在共享服务所在机器；提取文字会通过现有 Codex 配置交给模型服务。项目访问者共享文件访问权限，不提供逐用户私密附件。

## 升级提示

- 五个平台的版本包仍同时包含 Share/CLI 与桌面控制台，已包含文档解析依赖，无需额外安装 Python 或 Word；仍需本机安装并登录上游 Codex CLI。
- 等待正在执行的任务结束，备份 `lan_config.toml`、隧道配置和完整 `runtime/`，再手动停止旧程序、解压新版并启动。不要用示例配置覆盖私人配置。
- 文档原文件、预览缓存与消息关联位于配置同目录的 `runtime/lan/documents/`，迁移时须一并保留；缺失原文件的附件无法预览或下载。保留 `runtime/lan/auth.json` 可延续已有有效登录。
- 源码用户需在实际运行服务的环境执行 `python -m pip install -r requirements.txt`；桌面源码环境继续使用原有桌面依赖。升级后手动重启 Share 并刷新网页；现有已打开页面不会自动切换到新版代码。
- 版本包未进行 Windows 代码签名或 macOS 公证，请核对随 Release 提供的 `SHA256SUMS.txt`。
