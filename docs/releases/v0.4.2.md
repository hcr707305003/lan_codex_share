# v0.4.2

## 新增功能

- 控制台关闭窗口时新增选择：隐藏到系统托盘、仅退出控制台并保留服务、停止本客户端服务并退出、取消。
- 托盘模式保持控制台、服务、日志、下载及配置草稿运行；点击托盘图标或菜单恢复窗口。
- 「仅退出控制台 · 保留服务」彻底退出窗口、托盘及 Qt 控制台进程，Share、frpc、Cloudflare 继续运行，不再必须保留控制台窗口或托盘。
- 控制台新启动的服务使用不加载界面的轻量运行进程，独立维持日志和控制管道。日志保存在配置目录下 `runtime/desktop/services/<服务名-随机标识>/desktop.log`，支持敏感内容脱敏和滚动保存（单份 5 MiB，两份轮转备份）。

## 功能修复

- 解决控制台直接退出后，Share 控制管道断开触发停止、隧道日志依赖控制台读取的问题。必须收到服务独立运行确认才退出；确认失败保留窗口供检查或重试。
- 系统无可用托盘时禁止隐藏窗口，避免无法找回控制台；仍可使用独立退出或最小化。

## 行为或兼容性变化

- 保留原有「停止本客户端服务并退出」和二次确认；不会关闭原本外部启动的服务。
- 未保存的配置在真正退出前仍会提示；组件操作、启动或停止操作未完成时会进行保护。
- 旧方式启动的服务不自动迁移、不自动重启；无法安全脱离时可继续保留窗口或使用托盘模式。
- 再次打开控制台沿用外部服务检测和防重复启动机制；不自动接管服务，外部 Cloudflare 仍仅检测。
- 托盘模式依然需要控制台进程存活；独立退出模式会保留无界面的服务运行进程。两者都不等同于开机自启，不保证注销或关机后继续运行。

## 升级提示

- 提供 Windows x64、Linux x64/ARM64、macOS x64/ARM64 五个平台包，包含 Share/CLI 与桌面控制台；仍需本机安装并登录上游 Codex CLI。
- 备份并保留私人配置和完整 `runtime/`，不要用示例覆盖已有配置。等待任务完成后手动退出旧控制台并换用新版；不要覆盖正在运行的程序文件。
- 由新版控制台新启动的服务支持独立退出。已经在外部运行的服务保持原状，无需为使用控制台而重启。
- Windows 包未代码签名、macOS 包未公证，请核对下载包与 `SHA256SUMS.txt`。
