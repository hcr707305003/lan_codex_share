# v0.5.7

## 新增功能

- 网页支持导出共享会话迁移包，可多选会话分别下载；支持服务器下载及断点续传。
- 支持导入原会话或导入为副本；副本使用新 ID 并添加名称后缀，可在本机 Codex 中继续。
- 迁移包不再设置固定历史大小上限，实际受磁盘和网络条件限制。

## 功能修复

- 导入登记和导入会话使用独立进程，释放时清理对应子进程，避免副本一直占用而无法在 Codex 客户端归档。
- 等待队列只展示真正排队的消息，修复失败任务残留且无法清空的问题。
- 改善 Windows 退出过程中的子进程已退出竞态及重复中断处理。

## 升级提示

- 保留配置与 runtime 目录，等待任务结束后退出旧 Share 并启动新版，以清除旧版本遗留占用。
- 提供 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 五个平台包。
- 会话导入发生在运行 Share 的电脑；目标电脑需安装 Codex。项目代码和外部附件需另行复制。
- 原 ID 导入拒绝覆盖已有会话；本机复制请选择“导入为副本”。原生导入依赖 Codex 的实验性恢复接口。
