# v0.1.5

## 功能修复

- 修复回复中的 Markdown 表格显示成包含 `|` 和分隔线的普通段落的问题。聊天回复、过程记录和右侧 Markdown 文件预览现在共用表格渲染，按表头、行和列展示内容。
- 表格采用清晰的表头背景、单元格边框和隔行底色；支持 Markdown 指定的左对齐、居中和右对齐，长文本及较长代码标识符自动换行。
- 修复窄屏阅读表格的布局问题：超宽表格在自身区域内横向滚动，不撑宽聊天页面或文件预览，也不挤出顶部栏。滚动区域可以通过键盘聚焦。

## 显示能力

- 表格单元格支持加粗、行内代码、网页链接、可点击的本地文件链接，以及 `<br>` 换行；聊天正文中的 Markdown 加粗也会正常显示。
- 支持省略首尾竖线的表格和使用 `\|` 表示的单元格内竖线。短行补齐空单元格，多余单元格按表头列数处理。
- 流式回复会在表头分隔行完整后显示为表格，并继续补充后续行；普通竖线文本和代码块中的表格示例不会被错误转换，任意 HTML 仍按文本处理。

## 升级提示

- 配置文件无需修改。版本包用户替换程序并重新启动 LAN Codex Share 后刷新浏览器；源码运行用户更新代码后刷新页面即可加载新样式和渲染逻辑。
- 历史消息会按新规则重新渲染，无需重新发送问题。
- 提供 Windows x64、Linux x64 / ARM64、macOS Intel / Apple Silicon 五个平台版本包，继续支持同一程序的 Share、CLI 子命令和 `--config` 参数。
