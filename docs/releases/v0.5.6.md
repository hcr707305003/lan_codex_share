# v0.5.6

## 功能修复

- Codex 文件引用指令现在显示为可点击的文件名及下载入口，不再直接显示指令文本。
- 独立 XLSX 文件支持右侧表格预览与工作表切换，复用受限隔离解析器，保留原文件下载。
- 表格预览展示已保存的单元格值，最多 200 行、50 列；不计算公式，不还原原始格式。

## 升级提示

- 提供 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 五个平台包，包含桌面控制台和 Share/CLI。
- 保留配置及 runtime 数据，待当前任务结束后自行退出旧程序并启动新版，再刷新网页。
- 源码用户也需要重启 Share 服务以启用 XLSX 预览接口。
