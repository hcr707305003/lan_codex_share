# v0.5.8

## 新增功能

- 左侧增加“搜索当前会话”入口，搜索服务端会话历史中的消息、回复及工具记录，包含浏览器尚未加载的历史轮次。
- 搜索结果按页展示匹配片段，提供关键词高亮与片段复制。
- 工具内容支持复制已显示文本，以及右键复制选中文字、复制本块内容和在会话中搜索。
- 复制兼容局域网 HTTP；Shift 加右键保留浏览器菜单。

## 功能修复

- 工具返回的文本展开显示，保留换行与缩进；代码参数单独显示。
- 原始 JSON 默认折叠，展开时才渲染；图片、音频二进制内容显示类型摘要。
- 工具失败结果增加明确提示，旧后端缺少搜索接口时提示重启 Share。

## 升级提示

- 本次包含后端接口变更，请等待任务结束后退出旧 Share 并启动新版，再刷新网页。
- 搜索范围为当前会话服务端保留的历史文本，不检索外部文件正文、图片像素或音频；已在源数据中截断的内容无法恢复。
- 复制本块针对已显示内容；搜索结果复制的是匹配片段。
- 提供 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 五个平台包，保留配置与 runtime 数据升级。
