# v0.1.1

## 新增功能

- 支持将 `session_ids` 配置为空数组，自动发现本机全部未归档的主 Session，并排除子代理任务。
- 全部 Session 模式在网页侧边栏按“项目 → Session”分组展示，项目可折叠，当前 Session 和运行状态清晰可见。
- Session 目录会定时刷新，新建任务无需重启共享服务即可出现；仅在首次打开时连接对应 Session，减少空闲连接。
- 文件预览授权会跟随已发现 Session 的真实工作目录更新，因此不同项目中的源码、Markdown、图片和 PDF 都能在右侧预览。

## 功能修复

- 修复全部 Session 模式下顶部固定 Session 选择器仍占用布局的问题。
- 修复目录刷新时单个 Session 恢复失败可能影响其他 Session 的问题；失败状态现在隔离到对应任务。
- 修复已结束或删除的空闲 Session 长期残留在共享目录和文件预览授权中的问题。

## 行为或兼容性变化

- `session_ids = []` 表示共享全部未归档主 Session；非空数组仍表示固定共享指定 Session。
- 完全省略 `session_ids` 和旧版 `session_id` 时，继续使用原有的单 Session 自动模式。
- 全部 Session 模式会将发现到的项目目录加入文件预览范围，只应在可信局域网中启用。

## 升级提示

- 需要全部 Session 目录时，将配置改为 `session_ids = []`，然后手动重启共享程序。
- 固定 Session 配置和旧版单 Session 配置无需迁移。
